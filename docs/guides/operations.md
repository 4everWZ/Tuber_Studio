# 评论、私信与动态运营

打开「自主运营 → 评论处理」处理自动与手动草稿，按授权审核、提交并核对回执。配对使用 Jetson 配置的运营模型。大肥鱼微调模型的台词共用精简 OC 卡，视频画面补读在设置中完成视觉资源验证后启用。Gemma 4 E2B、其他通用 VLM 和兼容 API 使用完整角色卡。[双机部署](deployment.md#电脑业务主机与独立推理节点) · [角色指南](characters.md#选择角色生成方式)

## 账号与登录

在「设置 → 账号与权限」保存 SESSDATA 和 CSRF／bili_jct，留空保留原值；更换或清除账号也在这里操作。点击验证或刷新后，该页显示平台确认的 UID、头像、硬币和粉丝数，未知统计显示「—」。服务重启或验证过期后显示待验证，保存凭证本身不表示已登录。

本机可直接进入工作台。远程管理登录和 B站账号分别保存，平台 Cookie 失效时到设置更新。远程访问和令牌配置见[部署与启动](deployment.md)。

## 自主运营与评论审核

「评论处理」使用横向状态选框查看待审核、待核对、处理中和已执行与历史，刷视频的实际回复也在同页展示。详情只保留保存、拒绝、发布、复制四个操作；发布一次点击即可保存当前正文并提交。同一角色的历史版本草稿仍可人工审核发布，保留原生成版本。调度细节可展开查看。读取视频或导入 JSON／CSV 与选择评论、生成和审核都在同页；导入后直接显示该视频，生成后自动定位本次结果。预览为可选操作。

左栏进入「自主运营」，首页只保留一个开始／停止，并列出当前开放的权限。视频、评论、私信和动态按「运营设置」中实际勾选的权限运行，开始不会打开其它功能。关网页继续运行，服务重启后待命。

首页活动按日展示，横向选择全部、视频、评论、私信、动态；视频显示真实偏好及是否主评、跳过／不发言理由；旧记录没有模型偏好时显示未知，不从发言推断喜欢，评论区分主评与楼内回复，私信显示对象和结果。简单统计与分页都在同处，详细调度过程按需展开。评论处理、私信和设置在内部页切换，不占左栏重复入口。

告警页点击「清除已读」后计数归零，刷新不会恢复旧告警；同错误再次发生仍会显示。达到实际发送限额会保存进度等待名额。

每日观看数与每视频每日成功回复数在同组设置，默认按 `Asia/Taipei` 计日，两项数量填 `0` 均为不限。开始一个观看任务计一次，继续或重启恢复不重计；标题略过、评论回访和草稿操作不计。主评与楼内回复在平台确认成功后合计该视频的回复数，未明确结果先核对。观看次数用完仍处理已有任务、评论和私信。自动批次没有固定整批超时，界面的细看数量与运行超时只用于只读预览。

暂停后保留原候选、选择理由、观看范围和评论位置，重新开始时接着处理。已有标题原样再出现会沿用略过决定，搜索继续向后翻页；已看视频作为评论回访，不重新生成主回复。行动理由显示具体内容原因，普通等待在详情中，同一异常合并次数；有历史引用的退役人设卡归档后仍保留原回复来源。

打开评论详情或选择一个私信会话后，可进入「用户档案」确认称呼、偏好和重要互动，或清空这个用户的档案。退出个性化后，评论和私信都暂停使用档案与累计好感度。

## 大肥鱼自己决定发动态

1. 在「设置 → 账号与权限」配置并验证共享 B 站账号。
2. 进入「自主运营 → 动态」。已发布的公开评论回复可作为来源；也可在来源记忆中勾选「允许用于公开动态」。未勾选的会话不会进入运营输入。角色故事会显示为虚构，保留虚构语境。
3. 可先点「评估并生成草稿」，查看决定、正文及引用来源。这个按钮不会自动发布，审核通过后可手动发布。
4. 在运营设置允许动态运营，并选择自动发布或待审核；开始自主运营后，角色按已保存权限判断是否值得分享及何时再看。开始按钮不会代为开启动态或自动发布。

新安装的动态运营保持关闭。默认每 30 分钟评估，发送至少相隔 6 小时，每滚动 24 小时最多 2 次尝试；可以降低每天额度、延长发布间隔。没有新公开来源、内容重复或额度已用完时等待。平台拒绝和不确定结果也占用尝试额度。

决定记录显示为什么发或不发、下次评估时间、角色版本和来源原句；动态列表显示审核状态、错误与真实平台回执。可在统一入口停止自主运营，或在运营设置取消动态权限。若显示「发布结果待核对」，可点「核对发送结果」只读查询原提交；匹配回执后同步本地记录，查不到或读取失败时保持待核对，不补发。

「运营记忆摘要」显示当前摘要的实际 token 占用、上限与带来源摘录。默认上限 2048 tokens，可在策略中调为 256–4096；它与 128K 活动上下文分开计量。公开记忆更新时覆盖当前摘要，不把旧摘要一直追加下去。撤销公开、清理原文或更换模型后，旧摘要会失效，待下一次评估重建。

切换角色或版本、删除来源、撤销公开都会使相关旧候选失效。公开标记不会延长会话的保留期限。更换模型／API 前先停止自主运营；运营共用当前文本模型，不额外驻留一份模型或 TTS。


## 私信工作台

进入「自主运营 → 私信」，使用设置页维护的共享 B站账号。启用私信后可手动读取最近会话，选择用户与来信生成回复，再审核、修改、复制或发送。已发送显示平台消息ID；超时或发送中断显示待核对并禁止重发。当前只处理正常文本来信，不将本人、撤回、群组或系统消息交给模型，也不标记平台已读。

需要自动运营时，在运营设置分别保存私信自动读取、自动发送权限，再开始自主运营。新启用只处理之后的新来信，不追发历史；手工选中生成仍先审核。可设置读取间隔、每小时／每天上限和同用户冷却，停止自主运营或取消对应权限可阻止后续操作。平台验证、权限失败在页内显示，不会代为绕过。

「允许模型把评论讨论转入私信」开启后，角色根据当前公开楼选择回复渠道；不适合继续公开讨论时，评论草稿显示「已转私信」，在私信页处理。收件人固定为原评论作者；模型不生成任意目标地址。充分材料下，渠道、行动与正文可在同次模型生成中决定；需要独立渠道判断时，使用其配置的输出额度（含思考），正常回复和摘要额度不变。结构化生成失败或渠道与理由矛盾时，带原输出与具体反馈继续判断，未完成则保留检查点。

评论详情和私信会话显示同一OC对同一平台UID的好感度与阶段。昵称变化不创建新关系，同昵称不同UID不合并，不同OC相互隔离。共享数值不共享私信正文；私信也不会进入动态素材列表。

## 联网取材与继续处理

刷视频、评论、私信和动态中，模型根据任务自行决定是否读取公开网页，不要求每次联网。读取结果补充本轮材料并保存来源；直播不接入这条多轮工具链。

### 生成反馈

正文不按固定字数截断。平台明确拒绝提交时，Agent结合原稿和实际错误决定修订、暂缓或放弃；原账号、收件人和来源保持绑定。人工发布产生的修订仍进入审核，自动模式继续沿用当前授权与额度。Agent暂缓后，也可自行改稿并重新审核，再直接发布这一修订版。

在运营设置中调整单个任务的自动恢复次数，默认8，范围0–64，0关闭自动恢复。任务详情显示原稿、反馈、修订、调用与token用量。自动刷视频不以固定整轮调用／token数或整批期限中断；单次输出、实际窗口、明确配置的恢复次数和取消仍生效。未完成任务保留检查点，可点「继续处理」。公私信路由未确定的生成原文到私信工作台查看。

发送超时或结果不确定时先点「核对发送结果」，查询匹配的平台记录；此时不会让模型改稿后重发。读取未找到记录不代表原提交失败，界面继续显示待核对。

## 大肥鱼表情包

在「素材 → 表情包图库」选择角色，预览已有鲸鱼素材及来源、许可，再按需启用；也可导入 PNG、JPEG、GIF 或 WebP，每张最多8 MiB。图库原件独立保存，不随媒体缓存清理；被草稿占用的图片须先处理对应草稿才能删除。

私信草稿可选择文字或单张表情包，选图后重新审核，最终只发送一条图片消息；原文字保留作审阅及文字替代。动态草稿可保留正文并附一张图，换图或清图后重新审核。评论目前仍使用文字。

模型自动选图默认关闭，开启后只从当前角色已启用的图库选择；选择失败保留待审。现成图库可直接使用，图片生成接口预留且尚未挂载模型。实际账号发图权限和 GIF 播放效果仍需单独验证。

## 缓存大小与清理

在「设置 → 存储与维护」查看音乐、语音、临时产物和浏览材料的已用／可回收／受保护容量，并设置最大缓存。独立直播工作台底部也提供缓存入口。浏览池默认512 MiB，任务和待审核候选引用的原文受保护。媒体缓存清理不删除独立持久化的已读材料与进度；没有任何现存原文支持的旧分析不能继续作为事实。音乐共用一个池，最高15 GiB，新安装默认15 GiB；旧在线缓存上限继续保留，浏览材料不重复计入音乐池。

「清理可回收缓存」保留曲库引用、当前／待播和刚上传素材。需要释放曲库原文件时，先从曲库移除条目，再清理；降低容量到受保护素材以下会被拒绝。模型、音色包、登录信息、原始项目素材、评论／私信记录和关系数据不受媒体清理影响。
