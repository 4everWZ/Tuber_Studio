# 评论、私信与动态运营

## 指定视频自动回复

在「评论」中填 BV 号或标准视频链接读取评论，也可导入已有数据。回复默认生成待审核草稿，支持修改、审核、复制与发布。

需要持续运营时，在评论设置填入关注的 BV 号列表并开启自动浏览。开启自动回复前配置账号 SESSDATA 与 bili_jct；保存后只有自动浏览产生的新草稿会按策略发送，人工选中生成的批次仍待审核。每小时／每天额度和停止按钮控制后续发送。关注列表为空时使用热门视频；本版不提供关键词自动搜索。

## 大肥鱼自己决定发动态

1. 在评论设置配置同一个 B 站账号。
2. 打开「动态运营」。已发布的公开评论回复可作为来源；也可在来源记忆中勾选「允许用于公开动态」。未勾选的会话不会进入运营输入。角色故事会显示为虚构，保留虚构语境。
3. 可先点「评估并生成草稿」，查看决定、正文及引用来源。这个按钮不会自动发布，审核通过后可手动发布。
4. 开启「动态运营」后，角色在后台判断是否值得分享及何时再看；默认允许直接自动发布。关闭「自动发布」则后台只生成待审核草稿。

新安装的动态运营保持关闭。默认每 30 分钟评估，发送至少相隔 6 小时，每滚动 24 小时最多 2 次尝试；可以降低每天额度、延长发布间隔。没有新公开来源、内容重复或额度已用完时等待。平台拒绝和不确定结果也占用尝试额度。

决定记录显示为什么发或不发、下次评估时间、角色版本和来源原句；动态列表显示审核状态、错误与真实平台回执。可随时点「停止动态运营」。若显示「发布结果待核对」，自动运营已经暂停，请先到 B 站核对，再决定是否重新开启；该候选不会自动重试。

「运营记忆摘要」显示当前摘要的实际 token 占用、上限与带来源摘录。默认上限 2048 tokens，可在策略中调为 256–4096；它与 128K 活动上下文分开计量。公开记忆更新时覆盖当前摘要，不把旧摘要一直追加下去。撤销公开、清理原文或更换模型后，旧摘要会失效，待下一次评估重建。

切换角色或版本、删除来源、撤销公开都会使相关旧候选失效。公开标记不会延长会话的保留期限。更换模型／API 前先停止自动评论和动态运营；运营共用当前文本模型，不额外驻留一份模型或 TTS。


## 私信工作台

进入「私信工作台」，沿用评论页的账号凭证。启用私信后可手动读取最近会话，选择用户与来信生成回复，再审核、修改、复制或发送。已发送显示平台消息ID；超时或发送中断显示待核对并禁止重发。当前只处理正常文本来信，不将本人、撤回、群组或系统消息交给模型，也不标记平台已读。

需要自动运营时分别开启自动读取、自动发送。新启用只处理之后的新来信，不追发历史；手工选中生成仍先审核。可设置读取间隔、每小时／每天上限和同用户冷却，点击「停止自动收发」阻止后续操作。平台验证、权限失败在页内显示，不会代为绕过。

「允许模型把评论讨论转入私信」开启后，角色根据当前公开楼选择回复渠道；不适合继续公开讨论时，评论草稿显示「已转私信」，在私信页处理。收件人固定为原评论作者；模型不生成任意目标地址。渠道判断沿用模型的思考和输出预算，结构化生成失败时保留来源并提示，可在纠正模型配置后重试。

评论详情和私信会话显示同一OC对同一平台UID的好感度与阶段。昵称变化不创建新关系，同昵称不同UID不合并，不同OC相互隔离。共享数值不共享私信正文；私信也不会进入动态素材列表。

## 缓存大小与清理

在「设置 → 媒体缓存」或直播工作台下方查看音乐、语音、临时产物的已用／可回收／受保护容量，并设置最大缓存。音乐共用一个池，最高15 GiB，新安装默认15 GiB；旧在线缓存上限继续保留。音乐池包括导入歌曲和在线音频。

「清理可回收缓存」保留曲库引用、当前／待播和刚上传素材。需要释放曲库原文件时，先从曲库移除条目，再清理；降低容量到受保护素材以下会被拒绝。模型、音色包、登录信息、原始项目素材、评论／私信记录和关系数据不受媒体清理影响。
