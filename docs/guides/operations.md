# 对话与社区运营

打开「自主运营 → 评论处理」处理自动与手动草稿，按授权审核、提交并核对回执。运营使用当前角色卡，后台选片、读帧、判断和拟稿使用 Qwen。取材带投稿文字、字幕、分 P 和时码。 [业务部署与服务接入](deployment.md#业务部署与服务接入) · [角色指南](characters.md#角色输入)

## 号主对话与取材

从「更多对话操作 → 私有语音通话」开始原生双工电话。聊天和电话共用当前角色的一只宠物，在设置里可以关闭 Pets。「播放静音」只管助手声音，麦克风继续采集。[私有语音电话与直播演出](private-avatar-call.md)

在聊天中交代要稍后完成的工作，或用「＋ → 交办任务」明确交办。打开「活动」查看取材、审批和结果；换设备继续看同一个任务。打开一项执行可设为长期目标、交办下一项工作，或授权它按本地时间每天／每周重读选定来源。停止执行与结束目标是两个操作，编辑成果也不会改变原始回执。

「结束长期目标」会停止该目标的周期和事件跟进。有在途执行时，先列出当前授权下将停止的任务；确认后不再接单、改口或审批。已开始的对外提交按原步骤核对，不重新发送。关闭页面或重启不撤销停止请求，历史和已保存的成果仍可查阅。

「活动 → 用文本附件交办」接受最多三份 UTF-8 文本、Markdown、CSV、JSON 或 SRT／VTT 字幕，每份最多 8000 字符。勾选「允许本次在隔离环境中运行 JavaScript」可以让工坊计算统计、整理字幕或输出文件，也可直接填写计算要求。每次计算使用独立的 QuickJS 进程，仅向脚本提供本任务的附件文本，限制内存和运行时间。文件在任务活动里下载。附件任务继续限制在私有工具内。

完成后在私有成果卡查看依据、编辑或下载 Markdown。打开提纲中的来源会另开标签，可直接返回原阅读位置。「历史成果」按任务修订号和成果版本保留此前正文，可在另一台设备上重新查看。

默认打开「对话」。用「＋」展开快捷操作，右上角菜单可清空私聊。可以直接问「今天有什么趣事」「第二件是谁说的」，也能从原始来源确认一条公开经历。输入「发个动态」可创建待审草稿，输入「开始自主运营」或「开启直播」可在会话中核对并确认。

「＋ → 交办任务」把工作交给常驻 Agent。到「活动」查看需要处理、进行中、已预约和已结束的任务，能展开来源、补充要求或停止。可以从「活动 → 预约任务」指定一次开始时间。关闭页面后，在线业务服务继续运行。视频取材沿用原队列与覆盖记录，直播素材先确认、播放结果按回执显示，模拟游戏动作在执行前核对控制权及局面。

「设置 → 个性化 → 记忆摘要」可问已有记忆，也可提出更正。明确指定的现有条目可以直接改，例如「把『运营汇报顺序』改成先讲结果」。需要推断目标时，先查看提议和原来源，再应用更正。

大肥鱼可以发随想、创作、日常或公开互动。要分享刚聊过的话题，可以在号主聊天里说「把刚才聊的布光写成动态」，草稿使用脱敏后的内容。引用评论时，预览图显示相关摘录和每条回复的对象，文字链接直达被引用的评论。活动列表里点击视频标题也会打开对应原评论，已确认回复有自己的直达链接。提交使用预览时保存的图卡和链接。业务主机使用系统中文字体，Linux 可安装 Noto Sans CJK。

输入「去刷视频：鲸鱼」可创建只读浏览轮次。说「把这个 BV 从头到尾看完」会优先安排该视频，默认看全部分 P，再沿原游标读到平台可见的评论末页。任务卡保留时码、原评论链接和缺口，也可从原任务续跑。日常有字幕时让角色先判断是否补看，缺字幕时按约 10–15 秒的故事板窗口扫描。「设置 → 后台 Agent」调整单批帧数，默认 5。

要看某一帧，可说「看一下这个 BV 的 P2，02:17.400」。已明确在聊哪个视频时可省略 BV。任务卡可展开查看实际画面，显示目标时码与取到的时码。播放流无法读取时显示回退使用的故事板和原因。

## 账号与登录

在「设置 → 账号与登录」选择「扫码登录 B站」，用 B 站手机应用扫码并确认。程序验证 UID 后保存该次会话的 Cookie 和续期令牌，设置页显示自动续期状态、最近核验及上次可用资料。也可手动填同次登录的 SESSDATA、bili_jct 和可选的 `ac_time_value`。只保存 Cookie 时显示手动续期。替换 Cookie 时，须重新提供同次登录的令牌才能继续自动续期。

服务重启后读取上次核验状态，后台复核会话。网络错误、风控和平台明确拒绝登录分别显示。B 站要求续期时，程序先保存新凭据，再用新会话确认旧令牌，确认中断后从原状态恢复。平台确认会话失效时，重新扫码登录。工作台远程管理登录单独保存。 [部署与启动](deployment.md)

## 自主运营与评论审核

「评论处理」使用横向状态选框查看待审核、待核对、处理中和已执行与历史，刷视频的实际回复也在同页展示。详情只保留保存、拒绝、发布、复制四个操作；发布一次点击即可保存当前正文并提交。旧草稿仍保留原角色与来源，是否可提交以当前账号和回执状态为准。调度细节可展开查看。读取视频或导入 JSON／CSV 与选择评论、生成和审核都在同页；导入后直接显示该视频，生成后自动定位本次结果。预览为可选操作。

左栏进入「自主运营」，首页可开始或停止，并列出当前开放的权限。视频、评论、私信和动态按「运营设置」中实际勾选的权限运行。关网页继续运行，服务重启后待命。

对话页顶部的「权限」可直接打开当前选项。评论、点赞和收藏逐项选择禁止、先审核或自动执行，更改一项只保存该项。「私信收取与回复」「发布动态」「私聊记忆」分别打开对应的设置。浏览权限和返回对话都不会启动运营。

首页活动按日展示，横向选择全部、视频、评论、私信、动态；视频显示真实偏好及是否主评、跳过／不发言理由；旧记录没有模型偏好时显示未知，不从发言推断喜欢，评论区分主评与楼内回复，私信显示对象和结果。简单统计与分页都在同处，详细调度过程按需展开。评论处理、私信和设置在内部页切换，不占左栏重复入口。

从「活动 → 异常」或顶栏告警入口查看近期记录，可按告警和错误筛选。点「全部标为已读」清除未读计数，刷新后仍可回看已读记录。同一错误再发生只计新增次数。达到实际发送限额会保存进度等待名额。

每日观看数与每视频每日成功回复数在同组设置，默认按 `Asia/Taipei` 计日，两项数量填 `0` 均为不限。开始一个观看任务计一次，继续或重启恢复不重计；标题略过、评论回访和草稿操作不计。主评与楼内回复在平台确认成功后合计该视频的回复数，未明确结果先核对。观看次数用完仍处理已有任务、评论和私信。自动运营与只读预览共用候选数量，指定视频可直接预览。选中观看后，工作台展示实际读取的字幕和抽样画面。配了多模态接口就尝试读取画面，单条失败会在详情显示。

普通停止后显示「正在收尾当前批次」。已接纳且可执行的任务继续处理，需等待的任务保存候选、选择理由、观看范围和评论位置。「运营设置」可紧急停止自动收发，重启后仍须手动解除。页内「运行记录」可按轮次查看处理结果，并展开取材、回复和耗时明细。已看视频继续作为评论回访，主回复防重照常生效。

打开评论详情或选择一个私信会话后，可进入「用户档案」确认称呼、偏好和重要互动，或清空这个用户的档案。退出个性化后，评论和私信都暂停使用档案与累计好感度。

## 大肥鱼自己决定发动态

1. 在「设置 → 账号与权限」配置并验证共享 B 站账号。
2. 进入「自主运营 → 动态」。已发布的公开评论回复可作为来源；也可在来源记忆中勾选「允许用于公开动态」。未勾选的会话不会进入运营输入。角色故事会显示为虚构，保留虚构语境。
3. 可先点「评估并生成草稿」，查看决定、正文及引用来源。这个按钮不会自动发布，审核通过后可手动发布。
4. 在运营设置允许动态运营，并选择自动发布或待审核；开始自主运营后，角色按已保存权限判断是否值得分享及何时再看。开始按钮不会代为开启动态或自动发布。

新安装的动态运营保持关闭。默认每 30 分钟评估，默认发送间隔 6 小时，每滚动 24 小时默认最多尝试 2 次。间隔和额度均可自行调整，填 0 分别表示无额外间隔和不限次数。即使没有新素材，大肥鱼也能主动分享兴趣、随想或创作。重复正文和已用完的额度仍会阻止发送。平台拒绝和不确定结果也占用尝试额度。

决定记录显示为什么发或不发、下次评估时间、角色和来源原句；动态列表显示审核状态、错误与真实平台回执。可在统一入口停止自主运营，或在运营设置取消动态权限。若显示「发布结果待核对」，可点「核对发送结果」只读查询原提交；匹配回执后同步本地记录，查不到或读取失败时保持待核对，不补发。

「运营记忆摘要」显示当前摘要的实际 token 占用、上限与带来源摘录。默认上限 2048 tokens，可在策略中调为 256–4096；它与所选模型的活动上下文分开计量。公开记忆更新时覆盖当前摘要，不把旧摘要一直追加下去。撤销公开、清理原文或更换模型后，旧摘要会失效，待下一次评估重建。

切换角色、删除来源或撤销公开都会使相关旧候选失效。编辑当前角色后，须重新启用自主运营。公开标记不会延长会话的保留期限。更换网关前先停止自主运营。


## 私信工作台

进入「自主运营 → 私信」，使用设置页维护的共享 B站账号。启用私信后可手动读取最近会话，选择用户与来信生成回复，再审核、修改、复制或发送。已发送显示平台消息ID；超时或发送中断显示待核对并禁止重发。当前只处理正常文本来信，不将本人、撤回、群组或系统消息交给模型，也不标记平台已读。

需要自动运营时，在运营设置分别保存私信自动读取、自动发送权限，再开始自主运营。新启用只处理之后的新来信，不追发历史；手工选中生成仍先审核。可设置读取间隔、每小时／每天上限和同用户冷却，停止自主运营或取消对应权限可阻止后续操作。平台验证、权限失败在页内显示，不会代为绕过。

开启评论邀请转私信后，程序按原评论的作者、回复对象和实际提及的 UID 确认邀请，并为原作者建立私信任务。大肥鱼拿着双方昵称和原话写正文。条件约定等待实际结果，普通讨论在评论区处理。发送前刷新原评论和会话，并检查收件人与回执。

评论详情和私信会话显示同一OC对同一平台UID的好感度与阶段。昵称变化不创建新关系，同昵称不同UID不合并，不同OC相互隔离。共享数值不共享私信正文；私信也不会进入动态素材列表。

## 联网取材与继续处理

刷视频、评论、私信和动态中，大肥鱼按需读取公开网页。中断续跑复用已经读到的摘录和已经校验的候选。直播沿用轻量取材。

### 生成反馈

正文不按固定字数截断。平台明确拒绝提交时，Agent结合原稿和实际错误决定修订、暂缓或放弃；原账号、收件人和来源保持绑定。人工发布产生的修订仍进入审核，自动模式继续沿用当前授权与额度。Agent暂缓后，也可自行改稿并重新审核，再直接发布这一修订版。

在运营设置中调整单个任务的自动恢复次数，默认8，范围0–64，0关闭自动恢复。任务详情显示原稿、反馈、修订、调用与token用量。自动刷视频按任务独立执行，沿用单次请求的输出和窗口设置。中断任务保留检查点，可点「继续处理」。无效输出与复读留在对应任务的诊断里供审核。

发送超时或结果不确定时先点「核对发送结果」，查询匹配的平台记录；此时不会让模型改稿后重发。读取未找到记录不代表原提交失败，界面继续显示待核对。

## 大肥鱼表情包

打开「角色 → 素材与表情包」管理共享图库。新增八张静态表情默认启用，原有 GIF 保留此前的启用选择。可以预览来源，或导入不超过 8 MiB 的 PNG、JPEG、GIF 和 WebP。图库原件独立保存。删除被占用的图片前，先处理对应草稿。

视频主评、楼层回复和动态可随正文附图。审核评论时核对 BV、楼层和父评，审核私信时核对收件人 UID。「选择表情包」只发单图，下方文字留作备选。「附图并保留正文」先发图片，再向同一人发送正文，两条消息各有平台 ID。换图或移除图片后重新审核。图片上传、分步送达和最终回执在草稿详情中查看。

视频主评、私信和动态分别设置「选用图库图片」和「调用生图模型」。图库自动选用默认关闭，生图沿用原有默认开启。接入工作站后，大肥鱼按当前草稿和渠道材料一次选择保留正文、附图库图或用 Q 版／常规版参考生成配图。动态换用角色配图时保留原评论出处。配图失败可在草稿中更换或移除。已有纯文字草稿保留原内容和授权对象。平台提交后断线时查看原回执，已送达的步骤不能重复提交。正式账号发图权限、公开可见性及 GIF 播放效果仍须以平台实报为准。

## 缓存大小与清理

在「设置 → 存储与维护」查看音乐、语音、临时产物和浏览材料的已用／可回收／受保护容量，并设置最大缓存。独立直播工作台底部也提供缓存入口。浏览池默认512 MiB，任务和待审核候选引用的原文受保护。媒体缓存清理不删除独立持久化的已读材料与进度；没有任何现存原文支持的旧分析不能继续作为事实。音乐共用一个池，最高15 GiB，新安装默认15 GiB；旧在线缓存上限继续保留，浏览材料不重复计入音乐池。

「清理可回收缓存」保留曲库引用、当前／待播和刚上传素材。需要释放曲库原文件时，先从曲库移除条目，再清理；降低容量到受保护素材以下会被拒绝。角色参考录音、登录信息、原始项目素材、评论／私信记录和关系数据不受媒体清理影响。
