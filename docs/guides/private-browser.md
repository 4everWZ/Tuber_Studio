# 交办并接管公开网页阅读

在「对话 → 活动」选择「用浏览器交办」，填写阅读目标和允许打开的完整 HTTPS 地址，每行一个。在已有任务详情中也可选择「授权阅读浏览器」。同一浏览任务最多授权六份文档；私有附件、代码执行和指定视频各走独立的授权入口。

打开任务的「查看阅读浏览器」可看到控制方、来源、最新 Chromium 截图和视口文字。「接管浏览器」会暂停角色操作。号主可以翻页、页内查找、展开折叠段、切换原生选项，也可以打开已授权的文档链接。「交回角色」后角色从当前页面继续。「终止浏览」会关闭阅读页、清除文档缓存和视口；此前取得的任务回执保存在原私有任务。继续阅读须重新指定来源。

## 页面与网络

Studio 后端按原地址匿名 GET。每次解析都核验公网地址，连接固定到核验的 IP，TLS 仍校验原主机。重定向目标需要单独指定。浏览器使用全新的临时配置，通过私有管道运行；只渲染服务端取得的文档，后台模型只获得阅读控件、文字和来源回执。

阅读页支持 HTML 与纯文本，保留文档结构、内联样式、原生披露和选择控件。网页脚本、登录、表单提交、上传、下载和外部子资源均关闭。依赖站点脚本或登录后才能显示的内容需要另给可公开读取的来源。

## 恢复和运行资源

任务库保存授权的账号／角色执行范围、任务修订、控制版本和最近完成的阅读位置。接管和交回沿用同一 Chromium 页面。工作进程释放后按缓存恢复来源、滚动位置和原生控件；未完成的操作沿用上次已保存的视口。改口、任务结束、执行范围变化或授权到期都会终止旧授权。每次请求校验控制版本，两个设备同时操作时只有当前版本可以推进。

每份源文档最多 256 KiB；每次授权为一小时、120 次操作。Studio 同时最多保留两个阅读进程，空闲 45 秒释放。每次文档请求限时 7 秒，Chromium 操作限时 16 秒，并检查进程树内存。所有点击和滚动都在业务侧隔离进程中完成。

使用仓库锁定的 Python 依赖。Windows 默认启动新实例的 Edge Chromium；其它系统默认使用 Playwright Chromium，可用 `uv run --locked playwright install chromium` 安装。服务环境变量 `TUBER_READING_BROWSER_CHANNEL` 可以选择 `msedge`、`chrome` 或 `chromium`。Linux 运行账户需要可用的 Chromium 沙箱。

管理 API 使用 `POST /api/agent/tasks` 的 `browser_sources` 创建任务。现有任务通过 `GET/PUT /api/agent/tasks/{id}/browser` 查看和授权；`PATCH` 管理控制权；`POST .../browser/actions` 只接受持有控制权的号主操作。操作携带 GET 返回的 `version`，重新授权还要携带当前任务 `revision`。 [隔离验收](../../evaluations/results/private-browser-20261119.md)
