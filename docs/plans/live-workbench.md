# 直播工作台与点歌

当前交付范围：独立直播工作台、可拖拽场景、现成歌曲正常播放、歌词与基于独立人声的口型。TTS继续说话；演唱只保留模型挂载接口，不纳入本轮音质／模型实现。行为与验收以[直播规范](../specs/live-and-media.md)及[声音规范](../specs/models-and-audio.md)为准，操作见[使用指南](../guides/live.md)。

## 当前边界

- `/live`支持拖拽／缩放、图层属性、画布尺寸、布局保存／恢复、重置保护和静音预览；与`/overlay`复用场景渲染器，保留单一播放者ACK。浏览器已检查桌面／手机、拖拽保存后刷新恢复，手机无横向溢出。
- 曲库支持WAV导入、来源／用途记录、候选确认、点歌排重、冷却、有界队列、重排／移除和请求快照。直接播放已通过真实浏览器音频／歌词、暂停／恢复与静音检查，歌曲不写入对话记忆。
- 现有六套GIF保留，唱歌开／闭嘴提取同一固定版本图集第12／13帧，来源在角色manifest与`third_party/whale-avatar/UPSTREAM.md`。当前直接播放可按独立人声活动呈现跟唱视觉，保留实际音源标识；无新生成角色图片。
- `SingingProvider`默认未挂载，界面禁用演唱模式。接口测试只验证挂载、声音／模型身份、缓存与取消等边界，不证明模型能唱歌。[先前候选试听与资源结果](../../evaluations/results/singing-candidate-20261030.json)未获用户接受，具体模型实现与依赖不进入产品交付，不再沿该候选调参。
- 原有瑶瑶说话、Genie／Mini128K共驻与Mock播放的[验收证据](../../evaluations/results/yaoyao-v2-voice-20261030.json)继续适用；本轮不替换说话声线，也不将浏览器检查当作OBS或真实平台验收。

## 未完成验收与后续范围

可选在线点歌的[本机实测记录](../../evaluations/results/online-song-requests-20261031.json)包含真实波点FLAC／320 kbps MP3、既有浏览器播放器及歌词时钟、关闭与重启、844项Python和3项Node检查；不替代下表的咪咕、目标设备／OBS及真实平台验收。

| 工作 | 对应要求 | 下一步／证据边界 |
| --- | --- | --- |
| 最终场景与OBS验收 | UI-08、AC-09／16–19 | 现场核对OBS输出、透明背景、实际直播构图及人声／歌词／口型；本地浏览器截图不能代替OBS本体。 |
| 目标设备与恢复负载 | NFR-04／05、AC-13／17 | 按既有混合流量和两小时恢复条件验收；不因局部播放通过宣称完整P1调度／稳定性完成。 |
| 完整音乐策略 | MEDIA-05／06／07／12–14 | 可选在线检索／候选确认与波点音频在本机浏览器闭环已验证；咪咕缺MIGU_COOKIE、目标设备／OBS本体及可选容器变体尚未验收。歌曲中穿插讲话的ducking、完整公平调度和真实平台Adapter继续后置；歌曲与互动串行播出。 |
| 未来演唱模型 | AUDIO-10、MEDIA-08、AC-15 | 本轮只交付挂载接口；未来有合适模型时独立验证声线、旋律／节奏、歌词、延迟和资源，再启用演唱，不自动重启已否决的候选实验。 |

工作台布局、曲库／点歌队列、未来演唱Provider和overlay渲染分别维护职责，复用现有角色／声音／任务控制。媒体准备与实际播放事实分开，不为新界面复制运行时或模型进程。
