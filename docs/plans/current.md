# 当前交付计划

交付顺序为 B 站社区运营 → 直播；游戏实机为后续扩展 TBD，保留独立规范、离线模拟和未来实机目标。优先完成运营的取材、角色生成、草稿审核、授权提交和回执核对。默认部署由电脑承载业务、局域网内 Jetson 提供推理，运营默认用内建大肥鱼 OC 的自有微调模型。直播和点歌单列验收，游戏模拟与实机目标见[游戏计划](game-livestream.md)。[产品契约](../specs/tuber-studio.md)维护交付要求。

## 运营主线

先处理[推理配置与凭证边界](#推理配置与凭证边界)，再核验真实账号读取、渠道判断与获准写入。模型语义质量与真实账号发送分别验收，诊断如实保留；运行时依操作者明确保存的审核／自动发送权限，不另设隐式语义门槛。

## 直播工作台

直播台汇集本场正在发生的事。借鉴 OBS 的单一节目输出和停播控制，以及 YouTube Live Control Room 把场内聊天和连接问题留在同一视图的做法。工作台的预览始终静音，OBS 浏览器源持有唯一播放权。直播页显示 Mock 会话状态和播放器连接，两项独立。场景编辑、曲库和直播配置从直播台就近进入。 [OBS 控制布局](https://obsproject.com/kb/quick-start-guide/) · [YouTube 直播聊天](https://support.google.com/youtube/answer/2524549) · [YouTube 直播状态](https://support.google.com/youtube/answer/3006768)

- **节目与控制**放在顶部。显示当前曲目、实际音频进度或正在播出的对白，提供暂停队列、暂停歌曲、跳过和静音。播放器未连接、准备音频、等待确认和暂停各有状态。停止会取消本场队列，清空只影响待播。
- **点歌**在同一区域显示正在播放、待播顺序、请求者及在线准备进度。搜索和添加歌曲从队列入口打开，取消待播和调整顺序沿用实际队列。待确认的在线候选及音源设置归曲库页。
- **弹幕与对白**在同一直播台查看。本场弹幕和礼物按接收时间合并展示昵称、正文和处理状态，活动投票明细沿用分流。当前台词留在节目区，播报记录显示本场处理阶段和已确认播出的台词。字幕、角色口型和工作台进度以播放端的实际音频段为准。整条播完才记入对话历史，等待、失败和取消各有状态。
- **验收**已在独立 Mock 工作台实测入队、混合队列调序与竞态刷新、歌曲暂停和续播、播放器唯一性、预录音真实台词、断线恢复和新场次数据隔离。桌面、平板和手机尺寸已检查。OBS 本体以预录对白验证社区 Live2D 和透明 GIF 回退。 [OBS 记录](../../evaluations/results/live2d-community-obs-20261111.json)

## 工程收口顺序

### 推理配置与凭证边界

- 已拆分[推理诊断](../../src/tuber_studio/provider_diagnostics.py)和本机模型下载状态。自定义模型列表走 POST，已保存凭证只用于对应地址，常规 Provider 保存不变更节点配对。
- 大肥鱼 DoRA 在节点运营档提供文本和专用视觉端点。配对读取实际模型和窗口，画面取材独立验证，失败保留字幕路径。Jetson 的装配、回切及恢复步骤见[部署指南](../guides/deployment.md#电脑业务主机与独立推理节点)。
- 部署探测和评估统一使用 `/llm`，语音合成继续使用 `/tts`。外部脚本迁移见[部署指南](../guides/deployment.md#电脑业务主机与独立推理节点)。独立推理服务由操作者显式绑定可信网络地址，全本地启动器默认使用回环。

### 角色输入收口

- [角色提示路由](../../src/tuber_studio/persona.py)按实际模型选择输入。大肥鱼 DoRA 在回复、直播和动态使用共享短卡，内部判断使用身份锚，通用模型使用完整角色卡。切换保留角色版本、草稿、历史与任务证据。
- 素材缓存使用独立记录 ID，重读按来源内容判断变化。旧缓存引用仍可读取。评论筛选只接收最新请求结果，候选卡按实际正文刷新。

### 运营状态、模块与校验

- 推理和语音表单分别维护状态，主工作台与独立直播页共用请求客户端。权限矩阵同时涉及浏览配置和私信策略，验收保存、刷新、父控制启停保留渠道设置、部分失败和紧停，以服务端实际状态核对权限提示。
- 设置已突出 Jetson 配对，详细地址探测与资源诊断按需展开，候选列表显示可读来源和发布结果。后续继续用桌面与窄屏核对角色切换、审核和错误恢复，保留紧停与待核对回执的可见性。
- 通用模型基类已移至[数据模型模块](../../src/tuber_studio/models.py)，运营与浏览直接使用。已移除直播互动中对构造器固定对象的重复检查，发送授权和额度在预占事务内核对。

### 当前主线的剩余验收
