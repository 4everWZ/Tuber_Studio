## 模型与设备

运营和直播默认使用同一份 Qwen3.5-9B 微调发布，原生 262,144 上下文、Q4 K/V、思考开启。运营档已用于 AGX 的实际审核和诊断。配对评估中，微调版通用题为 93/120，同基座为 100/120，40 个 OC 场景胜 23 个，合成运营为 2/12。模型质量仍有缺口，本阶段优先修业务逻辑。 [配对评估](../../evaluations/results/dafeiyu-clean-9b-20261111.md) · [部署与审核证据](../../evaluations/results/review-agx-mainline-20261111.md)

- 下一轮模型发布仍使用独立持出。120 条通用题分六类，相对同基座整体最多多错 3 条、单类最多多错 2 条。40 个 OC 场景盲评至少 24 个优于现行角色模型。发送路径另验目标、回执与私域隔离。
- 只有独立持出案例显示稳定缺口时，再决定补充角色场景或更换底座。训练先按会话与同源变体分组切分，再对训练分片加权。旧 SFT 验证集有 53/74 条完整对话与训练重合，用于训练诊断。继续保留原始语料和各自基座对照。
- 模型或运行参数更换后，分别验真实窗口、图像输入、解码速度和共驻时的整机内存及换页。外部 LLM／TTS 由使用者核对实际端点、模型、声音、容量和服务用量。 [推理与声音规范](../specs/foundation/models-and-audio.md)
