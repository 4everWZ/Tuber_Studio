# 游戏直播实施计划

游戏属于[常驻 Agent](current.md#常驻-agent-与跨端记忆)的目标范围。两款模拟覆盖共用工作台操作，星露谷隔离实机已验证局面读取、单地块农活与人工接管。后续按[游戏契约](../specs/live/game-livestream.md)逐款验收。双机迁移、运营模型和点歌的设备证据见[实装报告](../../evaluations/results/distributed-operations-20261102.md)。

## 现有离线能力

星露谷与植物大战僵尸已有进程内模拟状态及动作，工作台可查看、切换和驱动模拟。礼物互动与「你画我猜」已有离线事件和 API 测试。模拟证据覆盖状态推进与工作台入口，实机状态读取、动作执行、接管、独立存档和连续直播仍按下表验收。见[模拟实现](../../src/tuber_studio/live/game_livestream.py)与[离线集成测试](../../tests/test_interactive_live.py)。

号主对话可交给当前模拟游戏执行已有动作，卡片显示适配器返回的结果和存档状态。工作台可接管或交回，接管期间号主仍可手动操作，自动步进和对话交接暂停。两款模拟各自保存状态，业务进程重启后恢复。

购物／NPC／钓鱼／战斗等扩展以及C/S客户端保留在草案后续范围，首轮通过不冒称已交付这些能力。首轮目标完成后同步合同和证据，再按实际后续范围安排工作，不以无限扩展维持本计划常开。

## 基准与采用门槛

功能闭环与性能实验分别留证据。游戏连续实测待完成。

固定中文OC、多轮工具、图片／字幕、游戏局面、语音并发和点歌样本。拆分采集、媒体处理、上下文、网络、队列、视觉编码、prefill、decode、工具和首播，另报端到端，避免重叠相加。模型记录输入／输出tokens、prefill／decode速率、首个可见输出与完成；可观测思考和正文分开，未暴露阶段标为不可测。

记录业务及游戏端的资源占用，服务侧记录可取得的遥测。固定服务版本、窗口、图片、思考及输出预算和请求并发，分别报告冷启动、预热、样本数、p50、p95、最大值与失败率。单独核对直播响应期限。

先排重复执行与输入包装等业务热点。验证新服务版本时用相同局面和视觉样本，对比识别、动作选择、时延和失败率。改窗口、图片或预算时单列质量影响。

跨轮复用记录实际依赖与失效条件；角色、账号、模型、图片或会话变化时按对应依赖失效，避免串上下文。独立I/O可有界并行，推理、TTS和工具保留可观测调度与背压，不能仅增加并发后忽略内存争用和首字延迟。

采用需关键功能与质量无明显退步，并有可重复目标收益；通关／规划、事实引用、视觉、角色表现及错误率分别评审。保留必要回归和可复用benchmark，单次探针放tmp，未解决的空输出／重复／预算耗尽保留失败，先查请求、模板、参数与上游再比较替代模型。
