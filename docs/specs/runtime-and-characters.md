# 角色与运行时契约

## 角色、音色与素材

多角色配置具备不可变版本、复制、预览、激活和回滚；核心身份／人格／风格／规则与Lore、关系、场次状态分开保存。新OC复制角色卡后编辑核心和Lore，独立引用 `voice_profile` 与 `avatar_manifest`。复制默认可复用旧素材清单，业务调度和模型接口不含大肥鱼专属判断。

初始角色是社区二创风格的 DeepSeek Q版大肥鱼／鲸鱼娘：蓝白、蓝发、鲸尾、嘴硬心软、爱白饭和摸鱼；明确虚构AI主播、非官方账号。原型使用已有内容，素材来源、署名及使用约束可查看；商业模式不默认启用未授权音色。

模型输出只接受 `spoken_text`、有限 `emotion`、有限 `animation_id` 和可选 `reply_to`；引用只可指向当前事件。越界字段、非法标签／长度和控制字符不能转成工具调用。

`LLMProvider.generate`、`TTSProvider.synthesize` 可替换，初始使用MiniCPM llama.cpp及GPT-SoVITS HTTP接口。预录WAV可直通，不调用LLM／TTS；预录原型必须按实际录音显示字幕，不把录音冒称动态台词。缓存身份含Provider、模型／音色版本、参考音频内容、文字和有效推理参数。资产路径限于资产目录。

## 事件与调度

Mock支持chat／gift／song／disconnect／sfx，规范字段包括平台、房间、事件ID、用户ID、时间、内容、元数据。持久去重、TTL、过滤与有限队列；未知用户不按昵称合并。首版song会明确显示未实现播放，真实点歌与平台连接后置。

单LLM／TTS生成互斥区；基础礼物优先但与普通互动交替，P1音频时长配额另行实现。暂停阻止后续生成；静音、跳过、停止、切换角色及配置版本更新取消当前任务并通知播放器停音。清空队列不算播报完成。

任务为 queued → generating → synthesizing → ready_to_play → playing → completed，支路expired／failed／cancelled。只有单一overlay播放者持本次nonce先确认started、再确认ended，才completed并记入已互动上下文。缺播放器、播放错误、超时、断线、取消或重启均不算完成，不自动重播。新角色运行不能继承旧角色待播队列。

## 界面与隔离

管理区含默认评论工作台、总览、直播控制、角色、语音、素材、设置；展示实际队列、错误、模型／合成耗时、资源和上下文状态。管理API／WS需要认证；独立overlay凭证仅授播放／确认及媒体读取权，不能管理。

`/overlay` 支持透明／场景背景，角色、字幕、音频共用播放ID，素材缺失回退；断线立即停音频并清字幕。第二播放页待机，不抢占或重复播报。所有用户内容使用文本DOM展示。

SQLite保存版本、身份、会话、事件、任务和实际完成记录；大媒体在文件系统。重启取消遗留活动任务，保留完成记录。原始事件与对话按配置保留期清理，不把全部弹幕永久存为用户事实。

## 验收

角色复制／版本回滚和切换隔离、同昵称不同ID、持久去重／TTL／有界队列、非法模型输出、生成中取消、过期播放确认、预录直通、真实模型与动态语音、浏览器started／ended闭环。OBS软件本身、真实直播连接、P1负载与两小时稳定性单独验收。
