# 跨主机运行与数据归属草案

状态：后续阶段技术草案，维护游戏直播SRS实际v0.2提出的业务／推理解耦、唯一写入主数据、迁移和备份目标。当前安装与数据位置仍以[部署指南](../guides/deployment.md)为准；此草案不触发服务搬迁或改变当前默认部署。

## 职责与部署模式

后续推荐目标为“电脑业务主机＋独立推理节点”。浏览器作为B/S客户端，长任务、凭据、游戏控制和持久数据由业务后端管理，浏览器存储不是唯一副本。

| 主体 | 目标职责 |
| --- | --- |
| laptop／电脑 | 业务后端、Agent循环与上下文组装、记忆检索、工具、队列、平台接入、点歌Node、业务缓存、游戏／适配器／执行器、OBS与音频播放。 |
| Jetson或兼容推理节点 | 模型加载／卸载，语言、视觉及TTS推理；保存模型资产与必要推理缓存。模型产生判断，业务主机解释结果并执行工具。 |

保留同一主机承担业务与推理的全本地可选模式；它不等于离线，平台和在线点歌仍依赖网络。两种模式复用同一业务实现，以端点与部署配置切换，不维护两套Agent。业务代码不嵌入Jetson路径或某一模型参数；可替换端点须查询真实能力。C/S桌面壳仍为TBD，不作为本阶段前置。

## 数据权威与保留

| 数据 | 推荐目标下的权威位置与边界 |
| --- | --- |
| 评论、私信、直播／游戏互动及回复，角色版本、摘要、记忆、关系 | 电脑持久数据目录／数据库。按稳定账号、平台用户ID与角色关联，保留既有公开／私域访问规则。 |
| 配置、登录凭据、任务和动作记录 | 电脑持久数据，按身份与权限维护，并纳入适用的备份恢复。 |
| 歌曲／歌词／封面、网页视频、截图、工具结果、可重建音频 | 电脑业务缓存，受容量、活动任务保护、清理与失效规则约束。 |
| 游戏存档、主动保留录像 | 游戏／用户持久保存位置，不归临时缓存清理。 |
| 模型、声音模型及必要推理资产 | 推理节点模型管理目录，独立于业务缓存清理。 |
| KV／前缀及推理临时缓存 | 推理节点，可失效重建，不作为记忆、关系或历史主数据。 |

具体身份、版本和留存沿[运行时数据](runtime-and-characters.md)；窗口重建沿[上下文规范](context-and-compaction.md)。业务主机从必要近期对话、摘要、相关记忆与工具结果组装上下文，推理节点重启、卸载、KV失效或换端点后仍能重建，不依赖旧推理会话存活。

业务与角色记忆只维护一个可写主数据位置。迁移未切换前保留原权威位置；切换后电脑成为推荐模式下的唯一写入主机，旧副本不继续接受写入。

## 迁移备份与恢复

迁移前盘点路径、类别、容量及正在执行任务，分别处理持久数据、可再生缓存和模型资产。先备份，再在隔离目录核对数据库、角色版本、用户身份／关系、配置、引用文件与任务／动作状态；凭据备份保持适当访问权限。缓存清理不替代备份，备份恢复也不靠重新抓取历史补齐。

切换须明确旧写入者停止、完整性核对、新主机写入生效与回退边界；避免两端同时可写。原文件在核验后才按明确操作回收，模式切换或迁移本身不自动删除原数据和缓存。恢复演练不覆盖生产目录，恢复后先核对未决外部动作，再继续任务。

## 节点与业务服务中断

电脑是推荐模式的在线业务依赖。电脑关闭或后端退出后，推理节点即使在线也不独立继续运营、Agent循环或平台发送；重新启动先核对任务与未知动作。

推理节点失联时，电脑仍可查看历史、配置和执行不依赖模型的操作，相关模型任务显示等待／不可用。更换兼容节点保留业务历史、关系与游戏存档；模型失败、TTS失败、网络失败分别处理，不将等待当成功。

## 媒体地址与可选组件

点歌Node在电脑可启动、停止、重启，复用当前工作台、曲库、队列与OBS播放器；搜索、解析、下载与缓存由业务主机执行，电脑可读的音频不再经推理节点中转或重复下载。

媒体地址按实际播放器所在主机验证，某台机器的localhost不作为另一台机器可访问地址。OBS在电脑本地采集、合成游戏，避免将游戏画面送往推理节点再回传编码。

游戏截图、音频和可再生调试记录有明确的缓存目录、占用显示、容量设置与清理入口，复用现有活动任务保护。主动保留的录像、动作事实记录与游戏存档继续作为持久数据管理。

来源／音质、开关、取消、音乐池15GiB上限及受保护文件继续由[直播与媒体](live-and-media.md)、[媒体缓存](models-and-audio.md#媒体磁盘缓存)维护；本层只改变归属与寻址。两端显示各自缓存位置、占用和清理结果，模型资产、存档与持久记忆继续分开。环境镜像／源码分离与缺失才拉取沿现有部署规则，不为迁移默认新增基础设施或常驻模型。

## 跨主机验收

在隔离目录完成一次迁移／恢复演练，核对对话、角色、身份、关系、配置及未决任务一致性；清业务缓存后这些数据与游戏存档仍在，推理节点无另一份可写业务主数据。

分别验证推理节点重启／替换、电脑后端退出／恢复、跨机音频读取、登录持久性和原业务回归。迁移前后实测两机常驻／峰值内存、带宽、播放及业务延迟，不预设Node搬迁可释放多少内存。共享内存统计不直接相加，冷／热、缓存、并发与功耗条件单列。

此层提出职责和完整性约束；具体容器／进程、协议、路径与切换工具在设计时确定。模型与视觉量化、质量取舍的详细准入仍由现有模型owner维护。
