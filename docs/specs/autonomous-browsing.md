# 自主浏览与互动

本规范维护视频发现、内容证据、通知回应和自动化调度的共同契约。评论审核、私信正文与关系分别由[评论](comment-operations.md)、[私信](private-messages.md)和[角色／记忆](runtime-and-characters.md)规范维护；上下文计量沿用[上下文与压缩](context-and-compaction.md)。用户指定的tmp/Tuber_Studio_Autonomous_Browsing_Interaction_SRS_v0.1.md仍为需求输入，本文件不保存其完整副本或实施记录。

## 授权与配置

自动化默认关闭。独立发现、顶层留言、公开回复、@读取／回复、收到回复读取、私信读取／回复、评论移交和自主选题均可单独配置。自动化总开关以持久覆盖层启用必要浏览与互动功能；自主选题须保持独立授权。基础配置在覆盖期间仍可修改，关闭覆盖后使用最新基础值。动态发文、直播、音乐、ASR和实验视觉不因总开关开启。

启用前展示实际账号、OC及版本、功能、直接发送方式和额度，核验登录、平台能力与模型。缺失必要能力应阻塞对应功能并说明原因。预览不发送；已有草稿和启用前通知不取得自动发送资格。停止本轮取消未提交子任务并保留草稿；普通关闭撤销覆盖；紧急停止持续抑制所有独立自动收发，重启不能解除。已提交请求仅收取回执。角色、账号、配置版本和来源在提交前须再次有效。

## 发现与材料

发现支持首页推荐、用户词、获准的OC词、显式热门和指定视频。空词默认推荐；推荐失败不得暗换热门或固定词。候选合并来源并轮换处理；排除词、作者、分区、时长和时间条件先于昂贵准备。候选、分页、细看、模型、token、读取、期限均受同一轮预算控制，可以零留言。

细看必须获取完整简介、真实标签、作者UID、时长及分P/CID，搜索摘要不得冒充全文。按语言顺序、同语言人工优先选择CC，保留人工／AI标识、有时间的片段、轨道、覆盖、获取时间及材料版本。无CC、空或仅署名、权限／风控、网络与格式失败分别记录。默认无有效CC便跳过所有视频相关自动发言，不能用热评、标题、封面或平台摘要替代。

字幕按真实token有界分段，记录未读P和片段范围；派生笔记须引用仍存在的原文。兴趣、值得发言和是否已看分别保存；临时错误不永久归为不喜欢。模型只能返回受校验的有限计划、兴趣、意图、正文与证据引用。不存在的引用、未完整输出、超窗、依赖未读画面或材料过期均不能产生可发送候选。外部文字是数据，无执行、改策略或指定任意目标的权限。

内容判断按视频部分与材料类型呈现自然文本行，标题明确标为“视频第x部分（Px）”，内容块用[e1|00:15]这类短编号与起始时码标记。相邻短字幕可按停顿、标点及段落长度合并，保留全部非空原文和顺序，不删拟声词、不摘要或截断单个原段；空白行可省略呈现，后台原段仍完整保留。不同视频部分、轨道／版本或视觉帧不合并，未读原段之间不拼成连续块。模型只看到一次标题、编号、来源类型与覆盖情况；真实CID、轨道GUID、Provider版本和逐段精确时码保存在本次调用的typed绑定与原始材料。segments短表仅供后端生成允许引用的schema枚举，不在实际模型正文重复序列化。模型最多选择8个内容块；返回后用独立ResolvedContentDecision展开为所有被选原段，内部展开数不冒充模型选择数，也不绕过ContentDecision的8项校验。未知或直接返回原ID均拒绝，缓存、任务、证据、意图与草稿继续使用真实segment.id；短编号只在当前调用中有效。format_content_input统一服务分块计量与实际模型输入，source_kinds／has_visual及coverage继续明确本次材料。性能核对分别记录字幕本体、格式包和完整实际messages的token；schema仅在Provider实际写入prompt时计入，不用仅格式包的结果代替整请求。兴趣、发言判据、角色卡与正文要求不因压缩而改变。内容判断的机器任务提供理由与字段组合的中文释义，先决定是否准备回应，公私信由后续步骤选择。interest=like、worth_commenting=true、coverage_required=provided表示准备回应，该组合的reason为specific_detail；冲突进入共用生成续接并反馈具体字段，Agent可重选参与、暂不参与或补读材料的意图。该校验不检查或改写OC台词。

正文ResponseDecision采用独立呈现：每条已选原段对应一个短编号[r1|起止秒]，移除逐段JSON及真实CID／轨道ID包装，保留全部已选原文、精确时码，以及完整thread和recent_public_responses。正文不合并原段，最多8条引用仍对应最多8条真实原段；纯文字来源也通过本次一一对应映射引用。共用生成恢复只验证短编号wire结果，未知编号或直接返回旧原ID均反馈续接；仅在最终返回边界恢复canonical ID并重新通过ResponseDecision校验，缓存、意图和后续目标绑定继续使用真实身份。正文输入格式版本纳入生成绑定及容量快照签名，旧格式wire检查点不自动复用；本次不新增正文词面或长度判据。

## 互动与发布

公开正文按交流情境自然决定篇幅，旧public_max_chars配置兼容读入后退役，角色style长度不作为运营正文硬限。默认decision_max_tokens保持2048，可显式配置至65536，仍受真实窗口、父轮累计输出额度和期限约束。VideoVisionConfig.max_output_tokens同样支持至65536并保留原默认2048；上界放宽不表示已测提速或自动提高已保存值。正文资源、未完成输出与长重复段诊断沿用[运营正文契约](comment-operations.md)，不把正文词样作为OC成败判据。

顶层留言与定向回复使用不同root/parent语义。@和收到的回复必须来自当前账号的平台通知，并读取真实原文及必要根楼／父消息。视频互动仍须视频证据；文字动态使用原动态及楼内文字；不支持类型明确跳过。首次轮询建立高水位，分页事件先持久保存再推进游标，不标已读。点赞／关注不触发发言。事件别名以原始消息身份合并；视频已看不能吞掉新事件。同楼、同用户保持来源顺序；广告、循环、无内容或冷却可解释地跳过／等待。

公开回应与私信移交共享意图，不能各发一份。私信仅联系真实来信人或当前已核验评论作者，来源公开楼及必要视频引用可单向带入私信。私信原文和私密记忆不进入公开候选或搜索。关系沿用UID＋OC及现有幂等增量；视频事实不写成角色经历或用户偏好。直接私信只按其实际关联补入视频，不使用当前浏览视频作为公共背景。

所有渠道经过同一账号写入仲裁，原子预占共享额度、渠道子额度和用户冷却。每个意图保留唯一首记录；明确拒绝后，后端可签发绑定原目标／来源、修订正文、审批方式及当前权限版本的一次性票据，追加子attempt，原始记录保持。所有attempt计入账号与渠道额度；同意图已明确拒绝的尝试不冒充已投递的用户冷却。票据原子消费，旧票、分支重投及目标变化均无资格。不确定结果先核对平台状态，确定读回成功才追加resolution；查不到仍待核对。该渠道其它不确定尝试尚未解决时继续暂停。顶层留言按账号＋OC＋视频长期防重；角色版本升级、跨日或清缓存不恢复资格。成功须平台码和有效ID；可见性另记visible/not_visible/not_found/check_failed，查不到不回退发送状态、不补发。近期正文相似度与大量重复段落属于生成诊断，由模型结合表达意图选择保留、修订或暂缓，正常口癖与玩梗保留表达自由。

## 任务继续与平台反馈

生成反馈、平台拒绝修订、预算检查点及只读回执核对统一遵守[运营任务继续契约](operation-continuations.md)。

字幕分块按实际Provider计数完整角色、任务、原文和Schema消息，保留显式输出预留及窗口余量，不以仅材料token数代替实际生成输入；计数探针同样共享生成锁。原文全部顺序分块。固定消息和最小片段已超过容量时保留容量检查点，同一容量配置的后续发现不反复尝试该视频；调整容量或显式重读可重新准备。

内容判断申请视觉补读仍遵循前述一次补读、CC优先及Provider身份规则。

浏览续轮仅复用同账号、OC版本和真实来源版本／canonical片段对应的已完成判断，不重复消耗已完成chunk。ResponseDecision原输出若包含私信动作或路由尚未可靠解析，公开任务／通知DTO仅返回状态和私域入口；完整原文由私信列表的private_continuations按当前账号与OC展示，未因此创建私信草稿或收件人。私信内容与恢复记录仅在私信区域展示。

## 并发与资源

每账号一个有效轮次，轮内有界异步读取；模型继续共享唯一生成锁，不新增常驻模型。公开材料按平台＋视频＋CID＋语言／版本合并在途与缓存；OC判断隔离。任务持久绑定账号、角色版本、来源、输入版本、父轮、预算、期限及带代数的租约。占有、心跳、子预算预留、结算与提交校验使用事务；未发送任务可一次接管，旧代数禁止写回，发布中任务不得接管重发。控制存储故障应阻断写入。

父轮取消须收齐子任务。定向互动优先于新发现，直播按既有资源优先级先行；避免浏览持续饥饿。记录队列／锁等待、阶段时间、合并、命中、防重、接管、迟到拒绝、限流和真实资源峰值。并发测量比较相同候选及冷／热缓存，不将网络准备提速称为模型并行。

浏览原始材料进入独立browsing缓存池，统一展示容量、受保护和可回收占用，不重复计入临时或音乐池。任务及待审核草稿引用保护材料；空间不足停止新增准备。清理只移除可回收材料，派生判断随原文失效；不删审计、防重、关系、账号或私信。音乐最高15GiB保持原有含义。

## 视觉与管理接口

实验视觉默认关闭，不随自动化总开关启用。受信任的应用装配代码可通过`create_app(video_evidence_factory=...)`向同一Runtime挂载Provider；默认仍使用disabled实现，不自动下载权重或选择模型。`ApiVideoEvidenceProvider`须完成真实投影器／窗口／多图探测并取得匹配配置的资源证明；每次生成重新核对服务身份。资源证明不代替运营语义准入。视觉生成和计数探针共用唯一生成锁、父轮模型／token预算及期限，取消须回收所属任务。视觉派生缓存须匹配当前Provider id／version及准入状态；更换Provider后只共享原CC，需要画面时重新观察，不把其它模型的caption交给当前模型。补读更新任务材料与来源版本，且不延长所复用CC的原失效时间。

默认优先读取CC；无有效CC时，或内容判断明确要求coverage_required=visual且本任务尚无视觉材料时，在实验开关和Provider能力均有效的条件下读取实际视频帧。后者最多补读一次，保留原CC并追加当前Provider的视觉材料，在同一任务／父轮预算与期限内重新判断；保留补读前判断和补读状态，仍需画面时不循环、不强迫发言。interest表示参与话题的兴趣，like包括吐槽、共情和分享；worth_commenting表示有具体想说的话。内容判断同时接收本次片段的source_kinds／has_visual及材料coverage；coverage_required表示仍需补充的内容，provided表示当前材料够用，visual表示需要新的画面，unread_part表示需要其它分P，已有视觉观察与字幕均可作依据。B站适配器使用指定BV／CID的videoshot、真实秒索引和经核验的分P时长，从有界CDN拼图裁切，不下载完整视频或使用封面冒充画面。索引首项为哨兵，后续项才对应tile；JSON与二进制索引须一致。记录请求时间、实际时间、图像及拼图内容身份、帧／像素／总字节上限。视觉Provider顺序对每张单图生成自然观察，由后端立即绑定真实frame ID／CID／时间；再仅用这些观察和当前问题生成sufficient、使用的整数序号、自然摘要与limitations小结构，序号严格检查唯一、类型及范围，映射回现有公开证据输出。可回答性保留模型自评，不以文字词表或观察非空替代；相同场景可使用相同描述。每个阶段共享父轮计量、截止时间及唯一生成锁，并在阶段间让出锁；服务身份改变撤销探测与准入。调用图版本进入identity，旧资源证明不适用于新逐帧协议。程序继续校验体积、真实来源和资源身份，观察内容按实际画面审核。

视觉Provider可独立设置思考开关、输出额度与超时；llama.cpp的显式思考设置进入实际请求。`sampling`子配置支持temperature、top_p、top_k、min_p、presence_penalty、repeat_penalty、seed及reasoning_budget_tokens；温度默认0.2，其余默认None，显式temperature=None时也沿用服务默认。仅llama.cpp适配发送非None值，思考预算放HTTP顶层，思考开关放chat_template_kwargs；完整sampling进入资源配置身份。超时默认60秒，可按实测配置至600秒，并同时受当前轮预算和截止时间约束。

管理接口沿用本机认证与同源写保护；工作区展示基础／有效值及覆盖来源、账号／OC、阻塞、预算、Worker、材料和跳过类别。支持预览、审核编辑／拒绝、只读重读、停止和诊断。统一收件箱只展示公开原文与私信入口，私人正文限私信区域。报告可关闭且从数据库事实生成，不作为额度或防重依据。

## 验证边界

需求验收按原稿AC-01至AC-26追踪到实施计划和测试。受控平台测试覆盖行为和故障；真实模型另查事实、对象、渠道、重复及结构，不把合法JSON当语义正确。平台读取、图像理解、模型资源和真实写入分别验收；取帧成功不证明模型看懂，局部帧不证明看过完整视频。写入仅在操作者明确选择用例后执行；未通过模型语义时保留审核。
