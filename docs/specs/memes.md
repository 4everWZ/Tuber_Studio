# 角色表情包契约

本文件拥有运营表情包的素材、模型选择和图片传输约束；私信、动态各自保留来源、审核、频率与防重复发布的语义。角色直播表情动画仍由直播与素材规范维护。

| ID | 要求 |
| --- | --- |
| MEME-01 | MUST 优先复用已有素材或有清楚来源的图库，保留作者、来源、版本及许可。已有六个大肥鱼GIF原字节不改，初始可预览但未启用；启用、禁用、删除偏好跨重启保留。代码许可不等于第三方图包许可。 |
| MEME-02 | MUST 图库按OC绑定；模型只可从当前启用候选中选择一个asset_id或null，不能生成文件路径、URL、收件人或上传工具调用。人工选图及模型选择都须再次校验绑定、启用状态和字节完整性。 |
| MEME-03 | MUST 上传为内联图片字节，单图最多8MiB；只接受实际PNG／JPEG／GIF／WebP，并有原生解码、尺寸、帧数、超时与并发上限，不接受SVG、任意下载地址或本机路径。动画保留原文件，不能由此声称平台支持动画播放。 |
| MEME-04 | MUST 用户上传原件持久保存在独立图库，不作为媒体缓存自动清理。已有项目素材只做引用，不因图库删除而删除项目原件；正在审核、准备或结果不确定的草稿占用图片时禁止删除。 |
| MEME-05 | MUST 模型选图为独立的小结构阶段，不把图片ID混入正文JSON或让模型绑定账号。默认关闭自动选图；开启后仍沿用模型思考配置、生成锁与父轮预算，选择失败停待审，不自动发出替代结果。 |
| MEME-06 | MUST 私信在文字和单图片中二选一，切图后重新审核；原文字保留作审阅及文字替代，不暗中连发两条或作为已发送内容记入记忆。图文动态保留正文并最多附一图。图片草稿不能把复制文字冒充图文交付。 |
| MEME-07 | MUST 上传前检查授权，最终提交前复核来源、账号、角色、启用状态与发布权限，最终发布才预约同一来源的唯一意图。上传失败不代表已发消息，可重新准备；最终提交无有效回执、超时或发送中重启保留不确定状态，禁止自动重发。 |

模型选择只使用图库标题与情绪元数据，不宣称已理解图像内容。私信的简单问候、致谢、情绪互动可以选择单图；事实回答、重要信息及证据引用保留文字。动态图片不能替代正文的来源与隐私校验。评论仍使用文字回复，不由私信或动态图片接口推定具备评论图片权限。

管理预览可读取禁用素材，模型及发送流程不能。素材、绑定和占用保存在本地数据库，公开DTO不暴露内部路径；预览通过认证后的本地接口提供。共享文件内容按SHA校验，拒绝链接、目录越界、文件缺失或同长度篡改。可选生成模型通过`meme_generation.MemeImageGenerator.generate(MemeGenerationRequest)`返回`GeneratedMemeImage`原始图片字节，由`MemeGenerationService`复用图库原生校验、登记生成来源与声明许可，初始未启用；默认未挂载，不自动加载模型或调用外部图片生成服务，后续挂载仍需单独核验质量与设备资源。

实现参考[astrbot_plugin_meme_manager](https://github.com/anka-afk/astrbot_plugin_meme_manager/tree/d5e9475b00669aecd6596bf49af159c889725a3b)的分类、角色图库和受限选择方式；图片传输协议核对[bilibili-api-python 17.4.2](https://pypi.org/project/bilibili-api-python/17.4.2/)，不引入整套机器人框架或SDK依赖。已有鲸鱼素材继续使用assets/whale/manifest.json声明的作者与“大肥鱼项目署名许可1.0”，不是MIT图包。

验收分别覆盖原图与动图字节保留、角色隔离、无效ID与篡改拒绝、禁用与删除占用、模型选择失败、单条最终发布、上传失败后人工重试及最终结果不确定禁止重发。隔离HTTP／浏览器测试不替代真实账号的图片权限、动画效果或模型选图质量验证。
