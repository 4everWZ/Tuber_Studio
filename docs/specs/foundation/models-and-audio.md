# 模型、声音与资源契约

Core 按当前角色、授权、业务预算和网关实报能力生成回复、图片与语音，保存来源、产物与回执。推理调度由独立服务负责。[Omni 接入契约](omni-deployment.md)

## 角色声音与试听

| 声音身份 | 输入与行为 |
| --- | --- |
| `whale_reference` | 新安装默认。以登记的大肥鱼原声录音为参考，逐句朗读工坊提交的台词。 |
| `neutral_reference` | 新建空白角色卡的默认音色，使用内置合成参考音频。 |
| `yaoyao_reference` | 继续使用已选的瑶瑶参考录音。升级保留原角色的选择及参考材料。 |
| `whale_sample_v1` | 固定试听，只播放登记的样本及对应字幕。 |
| `external_api` | 保留已有显式 API 声音选择。工坊显示该身份，Omni 新句试听须另选参考音色。 |

角色的 `voice_profile` 引用声音清单。试听使用所选声音，直播使用当前角色绑定。逐项记录参考来源、署名、许可和版本；商业场景须具有对应授权。[声音清单](../../../config/voices.json) · [角色工作室](../../guides/characters.md)

私有通话用签票时选中的角色音色。浏览器从同源接口取参考 WAV，再签票并核对录音摘要。首个 `session.update` 带上参考录音，收到原生双工建连后显示角色与音色。参考录音读取和网关握手分别计时。切卡后结束旧连接，重新拨打获取新角色资料和参考录音。缺少适用参考录音时，角色卡是更换音色的入口。

### 工作站参考音色朗读

工坊向同一网关的 `POST /v1/audio/speech` 提交模型别名、指定台词和获准的参考 WAV。服务负责参考条件、推理和盲转写。工坊比对转写与原文，检查返回的 PCM、时长和非静音后保存。缺授权、参考不可读、错读或无有效音频时，记录该句失败。固定样本只用于试听自己的台词。

缓存绑定台词、服务地址、模型、声音版本、参考内容、协议及凭据作用域。声音或参考变化后重新生成。核验新参考时，用原参考中的同一句和一条新句实际重读，独立核对字词、声线与原录音，听感由号主确认。播放器播完后才将实际读出的台词记入历史。[直播播放](../live/live-and-media.md) · [参考朗读实测](../../../evaluations/results/omni-reference-reading-20261119.md)

### 说话与演唱能力

点歌播放已登记或取得的歌曲，语音朗读用于说话。演唱保留 `SingingProvider` 接口，默认未挂载。受信任的实现声明身份、版本与超时，接受已校验的曲目、歌词、角色声音和受控输出目录，返回成品、实际声音身份与可选人声轨。缓存另绑定曲目、歌词、引导材料和演唱版本。业务端校验音频、处理取消并等待播放器回执。启用前须另验歌词、旋律、节奏和声线。[点歌的两种模式](../live/live-and-media.md#点歌的两种模式)

## 接口与验收编号

| 编号 | 验证点 |
| --- | --- |
| AUDIO-01、AUDIO-02 | 用当前网关生成角色回复，校验 `spoken_text`、情绪、动作及可选回复对象；非法字段没有工具权限。 |
| AUDIO-03、AUDIO-04、AC-08 | 核对角色选择、参考来源、固定样本和既有配置的身份。切换角色或替换参考后检查缓存和私有通话的首个会话配置。 |
| AUDIO-05、AUDIO-06 | 相同输入可复用有效音频，静音或损坏的缓存不能送播。登记的叫声和感谢音效直接播放。 |
| AUDIO-07、AUDIO-08、AC-07 | 检查句长、分段、音量和合成超时。只有实际播完才写入历史；中断、拒绝或无有效输出时保留对应状态。 |
| AUDIO-09、AUDIO-10 | 核对使用场景的声音许可。演唱须另验歌词、旋律、声线和播放回执。 |

## 生成与资源验收

- 角色回复校验可见台词、情绪、动作与来源，运营判断使用相应受限结构。模型只能请求获准工具，执行结果由业务端核对并回流。台词和交付正文只取可见输出，思考占用生成预算。[上下文与压缩](context-and-compaction.md)
- 实际窗口读取已认证的模型卡。按实际输入计数并保留输出预算，分别验证结构化生成、长文答案和真实图像。视觉调用失败时保留来源和原因，有字幕则继续。[视频取材](../operations/autonomous-browsing.md)
- 任务按预算、队列、取消和截止时间执行。验收记录网关排队、首字、首音和实际完成。口型、字幕与播放时钟同步；预制音效按素材自身的声音与字幕播放。

## 媒体磁盘缓存

工作台设置与直播工作台须显示音乐、语音、临时产物的实际磁盘占用、可回收／受保护大小、写入状态和最大容量，并提供清理。音乐池合计导入曲目、在线FLAC／MP3与演唱输出，最高15360 MiB（15 GiB）；新安装默认15 GiB，已有在线缓存限额作为迁移初值保留。语音默认512 MiB，临时产物默认1024 MiB，分别可配置。在线点歌设置中的cache_limit_mib映射到同一个音乐池，不叠加第二份额度。

导入、在线下载和TTS写入共用所属媒体池的容量准入与LRU淘汰；超过剩余允许大小则取消写入并清理半成品。每池写入串行，音乐下载不阻塞语音池；每首／每次语音原有大小和时长上限继续生效。临时演唱工作区在准备前后检查保留容量，活动生成不被手动清理。

清理仅回收服务拥有的媒体缓存，保护曲库中的歌曲／人声／伴奏、当前／待播和新上传素材；降低上限低于受保护占用须拒绝，不先删原始曲库。移除曲库条目后才可回收其未被占用文件。参考音频、持久图片工件、账号、数据库及原始项目素材受保护，路径链接拒绝。清理同时失效在线／演唱索引，防止继续引用已删音频。容量、清理与对话留存是独立设置。
