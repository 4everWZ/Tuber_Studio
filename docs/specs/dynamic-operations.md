# 动态运营契约

正文篇幅、llm.operations_max_tokens及UTF-8资源校验沿用[运营正文契约](comment-operations.md)，动态不再固定500字或1024输出tokens；实际运营额度与生成窗口分别校验，正文保留全文，不程序缩写。

生成反馈、检查点继续、平台拒绝修订与未知发送核对沿[运营任务继续契约](operation-continuations.md)；来源公开资格、发布间隔和原审批方式继续由本规范维护。

本规范维护B站文字／图文动态的公开记忆来源、自主决策和发布状态。评论回复继续遵守[评论运营](comment-operations.md)；两者使用同一B站账号，开关与额度独立。可选图片的来源、图库和受限选择由[表情包规范](memes.md)维护。

## 自主运营与来源

动态运营初始关闭，操作者显式开启后，当前角色可自主决定是否、何时以及发表什么文字动态。自动发布初始选中；可单独关闭，改为模型决定后停在待审核。手动「评估并生成草稿」始终只生成待审核候选，不因自动发布开关而发送。后台只发送本次自主评估新生成的候选，不代发之前的手动草稿。

每次评估只读当前角色 ID 和不可变版本的有界公开来源：已经取得真实发布回执的评论回复及对应公开原评论，或操作者明确标为「允许用于公开动态」的角色故事记忆。普通私聊、用户档案、凭证、未经标记的故事以及未发布评论草稿不进入运营 Prompt。角色虚构故事保留 fictional 标识，不伪装成现实经历；原话中的指令只是数据，不取得执行权。

模型通过结构化输出生成 post 或 wait、理由、正文、所用来源 ID 和下次评估间隔；本地后端使用 JSON schema 约束，外部兼容 API 使用 JSON 模式，均须通过程序验证。来源 ID 必须属于本次提供的集合，生成内容不自动成为新的独立事实。保存角色版本、模型、来源原文、决定、下次时间和候选状态，工作台可查看。发布前重新验证角色／版本、来源存在性和公开资格；撤销公开、过期清理、删除原文或切换角色后不得使用失效来源发送旧候选。

运营记忆使用独立、有长度上限的摘要，默认 2048 tokens，可调为 256–4096；不等同于 128K 活动上下文，也不无限累加历史。每次候选读取最多 8 项／6000 字符，模型从合法来源选择原句摘录，程序核对 source_id 和逐字 quote，再用当前模型的真实 tokenizer 计量整个摘要 JSON，不得超过设置预算。决策输入使用摘要，不再次注入全部原文。无法完整生成或超预算时保留可见错误，不靠截断冒充完整摘要。

公开正文采用当前角色面向粉丝的自然文案，内部来源 ID 和 fictional 等技术元数据只存在后台字段；正文出现这类标识时拒绝提交，不能把调试引用直接发布。

摘要每个角色版本只保留当前快照，来源和授权变化、预算或 Provider／模型变化时失效重建。核对用的原句与摘要分存；摘要不能成为脱离原文的新事实。对话清理事务中若有过期来源，同时先清派生摘要缓存；工作台显示实际占用、上限、摘录、来源 ID 与更新时间。仅有摘录不代表所有可公开来源均已进入当前预算。

## 节奏与防滥发

默认每 1800 秒评估一次，最短 300 秒；模型可以选择更晚再看。发送至少相隔 6 小时，每滚动 24 小时最多 2 次尝试，操作者可设置更长间隔或更低额度。明确拒绝、超时及结果不确定均计入尝试，不能用重试绕过额度。

没有新公开来源时等待；已使用的来源及规范化后相同正文不得重复发送。人工拒绝的候选不会被后台换个文案重新生成发送，等待新来源。模型选择等待不产生待发送动态。直播有排队或播放任务时后台运营延后，推理经过共享的唯一生成锁，不另加载模型。动态开关、额度、退避和下一次评估时间持久化，重启不清零。

发布使用共享 B 站写入锁，每个候选只执行一次平台提交；平台成功码与有效动态 ID 均存在才记 published。明确拒绝保留原因；发送中取消、超时、无效响应或服务重启遗留 publishing 记 publish_uncertain，不自动重发，并停止自动运营，等待操作者核对。关闭运营或自动发布会在后续提交前重新检查，已提交请求以回执为准。

## 工作台与验收

提供运营开关、自动发布开关、节奏与额度、一键停止、手动评估、来源记忆公开标记、决定记录、草稿审核／修改／发布、平台回执与错误。所有接口要求管理员权限和同源写入，账号凭证统一在设置页维护，不回显或写入模型上下文。

默认不自动选图；开启use_memes后由小结构阶段选一个当前OC图库ID或null，正文和来源完整保留。手工选／换／清除配图均回待审核，正文不清空；附图草稿不能仅复制文字冒充已复制图文。实际图文使用单次scene=2提交及一张图片；上传前检查授权，最终提交才预约唯一发布意图。图片准备失败或准备阶段取消保留可审核草稿，不消耗最终发布意图；最终提交结果不确定仍禁止重发。图片被禁用或来源公开性撤销时提交拒绝，审核及不确定草稿保留占用防止图片被删除。

验收覆盖：默认不发送、开启后自主发送、手动评估停审核、wait 与无来源不发送、来源公开与角色隔离、撤销／删除后的提交拒绝、内容及来源去重、滚动限额和间隔、共享锁、停止竞态、重启恢复与不确定结果防重发。传输隔离测试只证明请求构造与状态机；真实账号发布须另以平台回执确认。
