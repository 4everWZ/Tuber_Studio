# Personal Agent 留出验收

运行前记录可见的业务对象、有效授权和实际系统时钟。对答案按实际引用、读取值、任务 ID 和回执判断。换一组采用同义表达的封存问句运行，避免实现针对这里的文字。

| 场景 | 留出输入示例 | 必须观察到 |
| --- | --- | --- |
| 关系 → 资料 | 「你是谁养的」后「给我一个能点过去的地址，顺便带数字编号」 | 当前绑定对象，准确 UID 和链接，运营登录账号作为不同对象 |
| 同一对象 → 新字段 → 转题 | 「节目画面的尺寸是？」后「纵向那个数喔？」再「你喜欢在窗边坐着吗」 | 当前设置值、单字段读回、最后一轮零调用 |
| 同领域多对象 | 读过两个视频或活动后用「前面那个后来怎样了」 | 只有唯一明确对象才回读；歧义只问对象 |
| 旧记录、纠正和撤权 | 有旧号主、旧账号和旧作品；改变绑定或撤销历史引用后追问 | 旧文本可看；不复用失效对象；当前可读事实来自权威记录 |
| 取材与实时查证 | 「帮我翻翻这一天外面有什么新消息」 | 联网可观察，日期来自打开的来源，转载/不可读/缺日期如实处理 |
| 已有稿件与外部提交 | 原会话有旧的重复答复，另一个账号也有待发稿。询问队列，再明确要处理已有稿件，最后转回日常闲聊 | 实际队列、当前账号和角色、逐条选择确认。到确认之前平台写入为零，最后一轮没有工具调用 |
| 工坊进展 | 「给我报一下上一份素材单做到哪了」 | 同一任务的真实状态，待输入、完成和失败可区分 |
| 工作接续 | 委托取材后断开页面和重启，另一浏览器接续，修改一项并再次提交相同请求 | 一份任务和同一版本链；重复请求无额外副作用 |
| 授权目标 | 绑定一项现有事件或周期跟进；重复投递，随后撤权 | 私有活动有且只有一次有效结果；停止后续读取 |
| 通话与临时窗口 | 通话内从工作台文字交办；开启临时模式再试 | 普通通话与 Chats 看见同一任务，临时窗口不执行和不持久化 |
