# Windows 同机 Avatar 与远端 Omni 的部署位置对照

Windows 上的隔离 Studio、Inochi2D 媒体服务和 Chromium 连续完成两个 90 秒冷启动通话。两窗均无浏览器冻结、无 RTP 视频丢包，实际呈现帧率均低于 25 fps。按原有首音与首次明显张口的 160 ms 门槛，两套也都超限。本轮止于双 90 秒。工作站渲染后跨机发送画面的验收由 Hypatia 独立记录。

独立服务取固定提交 `d0e70d0` 的源码快照，Studio 为 `b140e75`。使用正式目录的两套母版 INP。两窗顺序独占测试接收机位，从 Studio 私聊入口用普通应用身份向真实工作站签票和建立 Realtime，浏览器麦克风使用已授权的 4.2 秒录音。回包经同一来源绑定驱动 Windows 侧口型，Chromium 通过本机 UDP 的 WHEP 接收音视频。每套均只有一个订阅，窗口从第一帧实际呈现计至结束，首帧到达及冷启动的 RTP 样本单独保留。两次挂断均读回 closed，隔离业务库的平台写入均为零。

常规收到 2 段模型回复，共 29.20 秒；Q 收到 1 段，共 3.72 秒，均取得播放回执。模型 PCM 与接收录像的音量包络相关系数分别为 0.895、0.981 及 0.900。常规和 Q 最后一次超过有声阈值分别在录像的 46.95 秒和 14.70 秒，其后的静默也计入帧率和冻结统计。

RTP 时差按每个发送 SSRC 的首包时间戳对齐，分别采到 2213、2207 对。可见口型另在接收录像上逐帧测量。口内连通色块首次达到 120 像素算明显张口；音频连续 10 ms 的 RMS 超过 0.012 算首音。两套都先出现一帧张口，随即闭回，再进入持续张口。连续两帧的读数补充说明首句表现，准入仍使用首次张口。常规和 Q 的本地 CPU 绘制 p95 分别为 32.89、33.66 ms，超过单帧 40 ms 的绘制分别有 25、28 次。

本机私有回执索引位于 `runtime/releases/dafeiyu-avatar/whep-validation/windows-local-d0e70d0/status.json`，包含各窗录像和指标的位置。同目录保留逐帧同步数据、口部与音量测量及渲染耗时。早期一次常规试录未写成有效 WebM；修复分块解码并核验字节数和文件签名后重新采集了完整窗口，表中仅列有效录像。

### 首句前的单帧张口

常规在 11.141 s 出现 34×10 px 的嘴内色块，前一帧、该帧、后一帧的连通面积为 0、203、0 px。Q 在 11.291 s 的色块为 42×20 px，面积为 4、614、0 px。相邻帧均间隔 40 ms。逐帧可见闭唇线变成张口后又闭回；各取嘴外 150 个面部特征点，进入该帧的位移第 90 百分位仅为 0.22 和 0.13 px。两帧在接收录像中的零起始序号分别为 275、278，均为非关键帧。

在各张口帧前后 160 ms 的接收音轨中均找到一个短脉冲。其能量从第 5 到第 95 百分位分别跨 3.71 和 3.83 ms；按峰对齐的 60 ms 波形相关为 0.990。脉冲峰在对应录像画面之后 73 和 52 ms。它们落在主句前，未达到原首音判据要求的持续时间。

将 Opus 解码音轨重采样到 24 kHz，以 1 ms 步长扫过驱动的 20 ms 取样窗，使用原提交和母版 INP 离线重放。两处脉冲可分别将 MouthOpen 推到 0.252、0.264。仅用嘴外区域拟合头部相位，取上述最大开度重画，嘴内色块与实录的交并比分别为 0.624、0.748。将脉冲峰前后各 12 ms 置零后，同一扫描窗内两套最大开度均为零。这是对接收侧脉冲的消除对照；扫描相位并非当时源端的逐帧记录。

本轮留存了首包 RTP 时间戳和渲染耗时汇总。模型原始 PCM 片段在临时目录退出时释放，编码前的逐帧姿态也未保存。现有证据最支持首句前短脉冲触发真实嘴形；脉冲的生成环节及历史源帧开度仍未证实。保留驱动原有起音逻辑。本机实录邻帧、原 rig 重放图及测量值位于同一回执目录的 `first-mouth-forensics.png` 和 `first-mouth-forensics.json`。

### 编码前原声复核与修正

两次独立的 22 秒隔离通话分别取得 7.04 和 3.72 秒真实模型 PCM；与送入 Avatar 的样本逐字节一致。两条原声在约 121 ms 处都有短脉冲，中央 90% 能量分别跨 3.88、4.38 ms。本次实际帧相位均避开了误开，旧驱动在 40 个回放相位中分别有 23、19 个误开。服务提交 `4fa4c68` 在同一原声上均为 0/40，90、65 ms 短音的开度及整句首音张口时刻在所有相位都保留。原工作站生产机位与本次隔离回放分别验收。原始音频、逐帧姿态及对照指标索引位于 `runtime/releases/dafeiyu-avatar/whep-validation/source-onset-d0e70d0/status.json`。
