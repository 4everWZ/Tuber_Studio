# 私有通话语音交办

2026-11-20，使用工作站的实际 Omni 与后台 Responses、候选网关和隔离 Core。在 Chromium 中通过麦克风轨道播放两段中文合成测试录音。浏览器与网关在工作站内部网络连接。

- 核对直播状态的语音指令取得有效来话签名，只创建一项任务。重送同一转写返回原任务编号。后台以 `live_status` 的读回结果交付直播已停止的便笺。
- 交办后继续聊窗外下雨，原生双工继续发出音频和应答字幕。该句的辅助转写未完成，隔离库只保存了交办这一个话轮。
- 同一张任务卡显示完成结果。点击「朗读结果」后，当前音色的独立朗读播出一次。挂断及刷新后，原对话仍只有一个结果实例。隔离库有一项任务和一版交付，平台发布、账号写入、私信尝试及任务代回尝试均为零。
- 接口回归覆盖旧式签名、重送、换卡撤权、改口和取消。合成期间改口会使旧版朗读请求返回冲突。
