# Chats 前台路由回放 · 2026-11-20

在一次性业务库中使用工作站当前 Omni 和 Edge 的 Chats 页面。绑定号主资料与主页读回使用脱敏测试记录。回放只开放已配置网关的推理接口，平台提交尝试和待发队列均为零。

| 场景 | 观测 |
| --- | --- |
| 截图四轮及两条近义问法 | 两次主人提问都返回当前绑定昵称。两次近况和两次「在干嘛」都直接接话。工具回执、任务和设置变更均为零。 |
| 查画布后追问高度 | 第一次读回画布设置，第二次只读回高度 1080。转题后正常接话。 |
| 查询绑定号主主页 | 按角色绑定 UID 调用只读接口一次。 |
| 换成「开心蹦一下」 | 宠物回执、设置读回和页面实际解码的素材一致。 |
| 修改刚才的便笺委托 | 编号保持一致，任务从第一版进入第二版。第二版调用自主运营状态接口，收到待命回执，同任务的第二版便笺也写明自主运营未启动。 |

对浏览器收到的 SSE 最终正文与服务端只读回查逐轮比对，核对 Chats 页面显示。相关 Python 测试 207 项通过、3 项跳过，前端测试 22 项通过。

另一次回放中，后台同时提出多个调用，触发已有的并行校验。前台仍将修改绑定到原任务的第二版。
