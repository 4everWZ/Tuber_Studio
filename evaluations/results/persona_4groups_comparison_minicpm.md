## 核心结论与人设收益分析
1. **组 C（微调精简）对长 Prompt 依赖的彻底解耦**：
   - 组 A 需要输入多达数百 token 的详细人设系统提示词，但回复仍然呈现强烈的“模板拼接感”（例如在安慰场景里生硬重复口头禅“什么嘛，再来一碗白饭”）。
   - 组 C 在仅输入两行极简提示词的情况下，自主涌现出了极其生动的人设细节：“刚揭开饭锅那股热气”、“奇怪，尾巴怎么自己晃起来了”、“软垫给你，鱼鱼陪着你”、“贝壳灯挂到门边”。
2. **消除了原模型的自我分裂现象**：
   - 在场景 4（长剧情承接）中，底模（组 A）出现了严重的精神分裂式自言自语（“对了，你鱼鱼记得吗？记得，鱼鱼记得”）；
   - 微调融合后的组 C 与组 D 则完全以内置的“鲸鱼娘主播”第一人称自然承接剧情，把控了海底小屋的世界观。
3. **DARE-TIES 融合效果显著**：
   - 稀疏剪枝（80% 随机掩码）与符号对齐没有损害模型的流畅性，生成短句（30~43 字）极其干脆，非常契合直播弹幕与端侧实时 TTS 的播报需求。
