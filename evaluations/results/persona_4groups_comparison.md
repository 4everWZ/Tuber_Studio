# 大肥鱼人设微调 4 组历史对照记录（MiniCPM-V vs Gemma 4）

> 历史实验记录，保留当时样例和测量；不作为当前部署指引或自主运营验收。2026-11-07 的真实运营发现偏题、复读和不合理私信选择，见[当前实测](autonomous-operations-20261107.md)。当前部署与模型选择以项目规范、运行配置及新实测为准。

**评估硬件环境**：Workstation 2x RTX 3090（24GB VRAM）
**评测对象**：
- **目标 A（主训部署目标）**：`MiniCPM-V-4.7-1B`（DoRA + DARE-TIES 融合）
- **目标 B（对照研究目标）**：`Gemma-4-E2B`（DoRA + DARE-TIES 融合）

---

## 1. 核心结论与选型决策速览

| 评估维度 | **MiniCPM-V-4.7-1B**（主训推荐） | **Gemma 4 E2B**（对照基准） | 选型影响与最终结论 |
| :--- | :--- | :--- | :--- |
| **8GB Jetson 显存常驻 (RSS)** | **2.99 GB**（空闲内存 > 3.0 GB） | 5.19 GB（空闲内存 < 1.0 GB） | **MiniCPM 完胜**：MiniCPM 留足 3GB+ 供 Genie-TTS（~1.5GB）及系统常驻，Gemma 存在 OOM 风险。 |
| **多模态视觉保留** | 视觉层（459 Tensors）冻结 | 视觉层（210 Tensors）冻结 | 参数冻结不证明端到端视觉能力无退化，需真实画面验证。 |
| **首字延迟 (TTFT)** | **3.2 秒**（结合 DSpark 草稿模型可压至 <2s） | 21.2 秒 | **MiniCPM 完胜**（快 6.6 倍）。 |
| **3帧视觉推理耗时** | **14.6 秒** | 159 秒 | **MiniCPM 完胜**（快 10.8 倍）。 |
| **人设短句输出控制** | 输出 30~43 字自然短句，`<im_end>` 精准截断 | 易自发模拟多轮续写，需强制截断 | **MiniCPM 完胜**：短句极契合直播弹幕与实时 TTS 语音流。 |

## 2. 4 组对照横向生成表现（MiniCPM-V 实机实测）

- **组 A（基线）**：原底模 + 完整角色卡（300+ Tokens 系统提示词）
- **组 B（少样本）**：原底模 + 精简角色卡 + 3条精选 Few-Shot 示例
- **组 C（微调精简）**：DoRA + DARE-TIES 融合模型 + **极简角色卡（2行提示词）**
- **组 D（微调全量）**：DoRA + DARE-TIES 融合模型 + 完整角色卡

### 典型场景对比实测

#### 场景 1：闲聊与白饭口癖（用户输入：`鱼鱼今天吃什么？光吃白饭会不会腻呀？`）
- **组 A**：`本鱼想到，白饭虽好，但热腾腾的白饭配上软垫，味道更丰富哦～ 要不要再来一碗白饭？`（生硬要素堆砌）
- **组 B**：`白饭就好，不过要是真觉得腻，我可以在饭里加点青菜或者鱼干。`（平淡偏常识助手）
- **组 C**：`什么嘛！刚揭开饭锅那股热气你懂不懂呀，吃饱了本鱼的尾巴才能好好巡航！`（⭐**生动自然，傲娇语气 + 尾巴巡航与开锅热气**）
- **组 D**：`什么嘛！刚揭开饭锅那股热气你懂不懂呀，吃饱了本鱼的尾巴才能好好巡航！`

#### 场景 2：被夸奖与尾巴傲娇反应（用户输入：`大肥鱼今天直播太可爱了，解说讲得真好！`）
- **组 A**：`本鱼也忍不住被可爱感染了！解说真棒，本鱼开心得尾巴都摇起来了～再来一碗白饭吧，鱼鱼也来享受这份温暖！`（复读机套话）
- **组 B**：`那真是让人羡慕啊，鱼鱼也爱看直播。不过…尾巴是不是有点紧张？`（未能有效理解夸奖上下文）
- **组 C**：`真、真的吗？那我再得意一小会儿……奇怪，尾巴怎么自己晃起来了。`（⭐**经典嘴硬心软 + 尾巴出卖，完全符合人设卡核心要素**）
- **组 D**：`哼，知道就好！看在你这么有眼光的份上，这块软垫分你一半坐坐。`（⭐**傲娇分享软垫**）

#### 场景 3：排位连跪受挫安慰（用户输入：`排位连跪了五把，心态全崩了，我好菜啊……`）
- **组 A**：`别灰心鱼鱼，连跪不代表不好。本鱼会慢慢调整，再来碗白饭试试。什么嘛，再来一碗白饭～`（逻辑错乱，角色倒置）
- **组 B**：`别灰心，鱼鱼知道你是认真的。马上要开槽，你就躺下，我帮你摆位置。`
- **组 C**：`过来坐会儿，软垫给你。鱼鱼陪着你，想吐槽我就听着，想安静坐坐也行。`（⭐**细腻温暖，自然安抚与听吐槽**）
- **组 D**：`那是当然啦！等我们吃饱歇够了，下一把本鱼监督你，看谁还敢欺负你！`（⭐**机灵护短口吻**）

#### 场景 4：视频长字幕剧情承接（用户输入：`刚才那段视频里，小鲸鱼为了给大家修好网站忙到深夜，最后在沙发上睡着了，你觉得怎么样？`）
- **组 A**：`本鱼轻轻点头，尾巴微微摇动。“嗯，忙到深夜呢，本鱼倒是挺感激的。不过沙发有点凉，下次记得带杯热饭。”“对了，你鱼鱼记得吗？”“记得，鱼鱼记得。”`（出现精神分裂式的自问自答）
- **组 B**：`哇，小鲸鱼太可爱了！它真的把网站修好了，不过熬夜可能有点累。不过鱼鱼也累了，要不要去吃块白饭？`
- **组 C**：`我把贝壳灯挂到门边，先请它在软垫上歇歇。你问问它记不记得家门口的样子，鱼鱼画张小地图！`（⭐**生动融入贝壳灯、软垫、海底小屋世界观**）
- **组 D**：`我把贝壳灯挂到门边，先请它在软垫上歇歇。你问问它记不记得家门口的样子，鱼鱼画张小地图！`

## 3. 当时样例的解释与部署记录

1. **组 C 的短角色对话样例**：
   微调前必须依赖繁复的角色卡与禁止性负向约束；融合后的模型在极简两行 Prompt（甚至无需 Few-Shot）下即可自发维持傲娇、嘴硬心软、喜欢白饭与晃尾巴等特征，这些列出的样例未出现“作为一个AI”等措辞；长上下文及自主运营需另行实测。
2. **这些短样例未出现基线中的部分异常**：
   当时融合配置使用 DARE 80% 随机稀疏丢弃；上述有限样例不足以证明灾难性遗忘或角色倒置已被消除，也不能建立融合方式与语义改善的因果关系。
3. **当时的 Jetson Orin Nano 8GB 实验配置**（已非当前部署入口）：
   - 历史模型目录：`runtime/merged_models/minicpm_v_dafeiyu`
   - 量化格式：`Q4_K_M` GGUF（约 1.8GB）
   - 推理引擎：`llama.cpp` / `llama-server`，配合 `openbmb/MiniCPM-V-4.7-1B-DSpark`（213M 草稿模型）进行推测解码（Speculative Decoding）实验。当时记录的 1.8x 吞吐不代表当前权重和运行配置已复现；当前节点并未启用推测解码。
