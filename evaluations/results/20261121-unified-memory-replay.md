# 统一记忆查询实测 · 2026-11-21

用当前工坊 Omni 网关的 `omni-default` 和 `llm-default`，在隔离数据库写入一周前的观看片段、评论阅读记录和已送达回复，再加入 27 条无关的新记录。重启 Core 后，从 Edge 页面走 Chats 和动态工作台。

| 操作 | 实际结果 |
| --- | --- |
| 聊天说今天困了 | Omni 直接答复，后台工具调用为零 |
| 请大肥鱼回查鲸鱼相关的旧内容和出处 | Omni 选 `recall_memory`。后台缩短话题再查，交回观看片段、评论阅读和回复回执三个不同的来源 ID。聊天收到正文和来源 |
| 动态按鲸鱼话题评估 | 后台查最近三个业务日，再回查同一话题的旧记录，找回同三个 ID。动态评估选用原评和视频片段，生成一条待审核稿 |
| 查看「本轮取材」 | 评估前显示「暂无素材」。评估后展开视频片段，在新标签打开指定分 P 和第 19 秒。浏览器用测试传输核对完整地址 |

平台请求被隔离，动态尝试提交为零。回归测试核对同一原评在工具读取与模型请求中的去重、运营账号切换、私有偏好的用途隔离及撤销后的读取结果。
