## 重建与交接

`uv run --script tools/build_oc_avatar_rigs.py runtime/private-artifacts <母版目录> <新输出目录>` 校验四份输入后，用成图各自的标注绑定头、上身、双眼和发饰。闭唇保留原像素；口内是同一版本母版已有的口内纹理，转正、缩放后单独绑定开度及展圆。不依赖生成模型。目录名 `regular` 对应 mature，`q` 对应 Q；输出拒绝覆盖已有目录。

旧原稿仍可用[原构建入口](original-avatar-rigs-20261119.md)重建，本次重建的两个文件与各自已有 INP 字节一致。工作站独立交付目录的 `masters/` 保留这两件原稿，`regular/model.inp`、`q/model.inp` 分别为两件新 OC。私有 `registry.proposed.json` 将四个不同 ID 映射到四个相对路径，不是活动登记表。正式登记时需要只读挂载对应文件并保证服务用户可读；不要把交付目录的源图、音频和验收附件作为公开素材发布。

## 工作站验证

本页记录 INP 的隔离渲染验证。正式网关切换后的接收端语音、口型与短录屏见[两套成图的工作站 WHEP 通话](approved-oc-whep-calls-20261119.md)。

Linux 工作站上用隔离、无网络的短时容器运行独立服务 `4fa4c68` 的 `InochiRenderer`，没有启动媒体服务。按候选登记表的相对路径逐一加载四个 ID；每个读回 13 层，均实际渲染出 640×720 中性帧。两套 OC 另用 `evaluations/oc_rig_poses.py` 验了以下项目。

| 实测 | mature | Q |
|---|---:|---:|
| 中性帧相对成图的 RGB 各通道平均绝对误差（0–255） | 0.686 / 0.718 / 0.674 | 0.711 / 0.765 / 0.758 |
| 同时标，静音与角色 PCM 有声包之间的变化区域（左、上、右、下，右下不含） | 305,410,365,439 | 305,454,353,486 |

静音可见成图的闭唇线。有声样本张口，圆口与展唇可区分；逐图核对闭眼、视线和轻微头动。头发及鳍耳边缘在头动极值处有局部接缝，属平面拆层的限制。两份私有 `validation/*-poses.png` 按行依次是：成图／中性／头动，视线／闭眼／静音，语音／圆口／展唇。

复核时使独立服务源码在 `PYTHONPATH` 内，用该服务的 Python 执行 `oc_rig_poses.py <交付目录> <源图目录> <24kHz单声道s16le文件> <验收输出目录>`；源图副本名为 `regular.png`、`q.png`。本次是资产和渲染验收，不是连续中文口型、端到端同步、浏览器帧率或正式登记验收。旧稿的 WHEP 成绩不移用于新 OC。
