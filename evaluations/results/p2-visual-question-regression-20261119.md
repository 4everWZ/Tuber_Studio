## 原件、输入及漏判

r5 使用归档 P2 [0,10) 的第 38 个显示帧，零起算索引 37，25 fps。原帧可见锥形头饰、深色服装、蓝领和胸前金色图案，缺少识别防护用途和材质的独有构造。源采样字段记“红色官帽”。第一次审稿的标题观察库存则写“画面中央是一位身穿华丽服饰、头戴红色头盔的人物”。私有回归包同时保留两处观察及第二次提交的标题、完整理由、原窗和主帧绑定。

原候选来自 r5 私有归档 `review-evidence.json` 的 `editor_memory.review.attempts[1].submitted.items[0]`。含同词的观察来自 `attempts[0].titles["items.0.title"].observations[0]`。按候选的 `primary_frame` 在 `r5.json` 的实际取材步骤查找初采字段和时点，再按本场已核验的 P2 原窗解码。

问句原文为“画面中央是一位身穿华丽服饰、头戴红色头盔的人物吗？”。理由原文为“画面依据：画面中央是一位身穿华丽服饰、头戴红色头盔的人物。剪辑安排：用在开场，开场时插入片段，作为引子展示画面内容。”

修改前实际重放标题与理由时，一项对照只把“人物”改成“物体”，两边原样沿用了头部物名。标题单审同样只比较人物与物体。两次均无具体称呼异议。开发回放进一步发现，自由文字的局部观察问题会把待审名词先说给读图模型，导致相邻回放裁定不一致。

## 共同入口与留证

整句对照复用独立看原帧得到的初读。逐字段另取具体物名，检查该词是否真被前一个对照换掉。尚未核对的对象在原帧定位后，另一轮读图只收数字坐标与图像。模型提出的类别、理由、库存及自由文字定位问题都不进入这次读图。对照句仍保留原句语境；需要检验“另一类是否都是原类的一种”时，单独按两个词的外延复核。拒收定位到对照中发生替换的具体词，保留单独找到的具体修饰语异议。

返修库存选项及最终提交的未锁定字段都经过共同入口。私有任务的 `plan.visual_reviews` 记录送审原文、上游初采与库存、主帧坐标和时窗、整句与局部假设的对应关系、各阶段模型回包及逐字段结果。中断的调用保留已到达阶段，状态为 `incomplete`。

## 重放

本机私有目录 `runtime/private-artifacts/p2-visual-r5-regression/` 保存 `cases.json`、三个真实 MP4、修改前 r5 回包 `r5-prechange.json` 及最终回包 `coordinate-review.json`。原始回包、候选文字和媒体只在私有归档中流转。工具先核对源窗文件并用已有验收工具解码验证帧数和时长，再用生产解码器按真实呈现时点取帧。冻结回放逐次核对含实际图像的请求、响应契约、回包和完整裁定。

```powershell
$cases = 'runtime/private-artifacts/p2-visual-r5-regression'
uv run --locked python -m evaluations.p2_visual_regression $cases --frozen "$cases/coordinate-review.json"
```

普通应用网关连接就绪时，使用 `--live` 指定新的私有结果文件。Windows 隔离检出发起的正式网关回放六项及额外标题单审均命中，七组调用次数依次为 7、7、13、8、11、14、7。离线重放 67 个真实回包一致。视觉、归属、视频编辑、逐候选恢复、私有编辑契约和任务委派相关测试共 165 项通过。

工作站另起只读根文件系统的私有容器，使用同一版审稿代码、同一组 MP4 和本机普通网关，独立完成七组共 67 次模型调用。表中每个字段的结果均与 Windows 发起的回放相同。工作站再用禁网容器重放自身冻结回包，七组全部复现。工作站私有审稿目录内的 `result/gateway.json` 已原样归档至本机同一目录下的 `native-coordinate-review.json`。同场业务库未挂载到验收容器。
