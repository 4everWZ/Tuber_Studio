# 私有视频提纲的单字段修订回放

真实工作站和公开只读视频回放复用了同一任务的首版前检查点。检查点保留已经过审的第二项，仅第一项标题待改。工坊重新审读原主帧并保存首版。独立 Chromium 从普通聊天提交保留第一项、替换第二项的要求，路由回执与持久任务均指向原任务。

| 核验对象 | 实际结果 |
| --- | --- |
| 首版恢复 | 只更改待修标题，第二项、第一项理由、证据及窗口逐项相同。 |
| 普通聊天改口 | 新修订保留首项全文与证据，第二项采用与首版两窗均不重叠的新短窗。原版仍可读；点击原片回到原阅读位置。 |
| 来源与执行 | 两版的每项均保存投稿署名、独立节目页及分 P 时码。平台写入尝试为零。 |
| 主帧独立核验 | 重新从公开源解码三窗，对应 145、75、75 帧。三项标题、理由及用途均通过主帧核验。 |
| 整窗独立核验 | 自动审查未通过。部分帧组返回无法判断，另有制作评价与作品名称被判为剧透。原判和成品均保存在私有目录，本场未记为整窗自动通过。 |

实体提取仅接单个待审字段。使用真实历史拒稿复测时，服饰与头饰描述没有产生具名关系；包含演员姓名的对照仍需人物身份依据。屏字片段、正式署名、作品类型和镜头归属分别按其对应回执核对。
