# 两套母版的半身绑定

常规与 Q 版取两张设定稿的右上半身，使用原图像素及人工轮廓。两套 Ditto 的实测记录了自动注册失败与校准后仍不能闭唇的独立证据。[Ditto 工作站回放](ditto-master-mouth-20261118.md)

用 `uv run --script tools/build_original_avatar_rigs.py <母版目录> <私有输出目录>` 重建 `regular/model.inp` 和 `q/model.inp`。输入为 1448×1086 的 `original.png`、`Q_original.png`。每套含 13 张纹理，分别绘制肩背、脸与头发、鳍耳、发结、刘海、口内、闭唇、两侧眼白与睫毛、虹膜与闭眼睑。遮挡处使用邻近原画像素补足。原稿像素、可编辑模型与录像留在本机版本目录。

口部开度和展圆分别绑定，闭唇线只在接近闭口时出现。双眼分别支持闭合，虹膜随视线偏移。头部轻微侧转、侧移和缩放，鳍耳与发饰使用各自的位移曲线。同一姿态从 INP 参数和图层计算。两套文件均由 Inochi2D 项目的 Rust 工具 `parse-inp` 成功解析，各读回 13 张 PNG。[Inox2D 源码](https://github.com/Inochi2D/inox2d)

## 本地口型预览

使用同一句普通话「慢慢闭上嘴巴。泡泡浮出水面，鱼也笑眯眯。停一停，再陪你说一句。」桌面中文语音合成提供固定输入。两段 640×720 MP4 各有 341 帧、时长 13.64 秒，音轨前置一秒静音，整句结束后再次开口并在一秒处截断。声轨和图像均以同一 PCM 采样位置生成。用独立服务的 Inochi 渲染模块确认完全闭唇、开口、闭眼和视线偏移；预览中的打断来自截断输入。

| 本机离线逐帧耗时，编码同时运行 | 常规 | Q |
|---|---:|---:|
| p50 | 36.61 ms | 34.84 ms |
| p95 | 48.65 ms | 45.78 ms |

本地编码器按输入 PTS 编写每秒 25 帧。正式准入另计工作站通话的浏览器实呈帧率、冻结、口形时标、撤回、打断与同服务 Responses 共驻情况。[工坊私聊入口](../../docs/guides/private-avatar-call.md)

另以同一台桌面的中文语音分别合成「一、屋、鱼、欧、啊、八」。将单声道 24 kHz PCM 按 20 ms 送入服务端实际的 `render_pcm`，读取送给两套绑定的 `MouthForm`。响度超过 0.03 的窗口中位数依次为 +0.715、−0.598、−0.220、−0.312、+0.085、+0.135。正值展唇，负值收圆。全零 PCM 的 `MouthOpen` 为 0。这一对照检验固定音色的嘴形驱动，跨音色及连续语句的音画对齐以浏览器录像评估。
