# 私聊回查长期目标与历史成果

在临时 Studio 业务库中建立长期目标、子任务和带出处的选材原稿，保存号主改稿后再创建 54 项任务，使原任务退出活动列表。测试通过认证私聊入口按任务 ID、BV、完整来源、理由原文和目标查回成果。路由由脚本化模型驱动；查询、版本读取、权限校验和浏览器均使用实际实现。

- 编辑角色卡或更换运营账号后，号主能回读同角色的原稿。改口仍受原执行授权约束。跨角色、未映射作用域及已撤销记忆的版本不可召回。
- “我上次为什么选那段？”可以回到上次讨论的版本；如果号主编辑后的稿件另有原稿，语义路由可选择原版核对理由。原稿与号主改稿使用各自的版本坐标。
- 真实 Chromium 从对话输入问题、展开回答下的原稿并核对来源链接，刷新后再次打开同一版本。公开动态、直播交接和临时聊天未获得回查正文。关闭历史引用后再次打开来源被拒，生成中关闭时没有输出正文片段。
- 本轮未调用工作站推理，平台写入为零。联合运行私有任务回查、记忆、私聊、任务身份、创作工作区和 Omni 隔离回放，共 76 项通过。

复现专项目录中的测试可运行 `uv run --locked pytest tests/test_private_task_history.py -q`。设置环境变量 `TUBER_TEST_CHROMIUM=1` 运行其中的真实浏览器用例。Windows 使用新启动的 Edge Chromium 实例，其它系统使用 Playwright Chromium。

## 真实 Omni 私聊回放

通过普通 Studio 服务凭据调用工作站 Omni，私聊 HTTP 接口要求认证。业务库、号主会话和素材均为本次临时创建。出站传输只放行配置网关的模型卡、计数和聊天端点，调度器未启动，领域动作只允许澄清。

- 私有任务先保存角色原稿 r1 v1，再由号主编辑成 v2。创建另外 51 项任务、切换运营账号后，旧任务退出活动列表，仍可读取，执行授权已经失效。
- 号主通过普通私聊问“我上次为什么选那段？”。早期自由生成将原稿没有的音量及听众感受写入回答。改用版本和原文行选择后，真实 Omni 选中 r1 v1 第 2 行。工坊再次回读同一版，逐字比对后显示“选材理由：两声木鱼之间留出了报幕的节拍，主持人正好能在这里念出节目名。”回放按整段可见答复与原稿行的精确一致验收。
- 指定只看号主编辑的 r1 v2 后复问理由，该版只记载了修改结果。实测返回“号主编辑稿 r1 v2里没有可核对的对应理由。”，仍可打开 v2；这轮计数和生成请求均未收到 v1 的理由正文。
- 通过偏好接口关闭历史引用，原稿入口返回 404，回读旧回答已隐藏引用正文。原样复问，Omni 回答“你指的是哪一件事？”。复问的模型计数与生成请求均未收到任务 ID、原来源及选材理由，回复没有引用卡。平台写入为零。
- 可复现命令为 `uv run --locked python -m evaluations.omni_task_history`。通过环境注入 `OMNI_GATEWAY_URL` 和普通 `OMNI_GATEWAY_TOKEN`，也支持现有的 `OMNI_STUDIO_TOKEN` 或 `OMNI_CORE_TOKEN_FILE`。缺少配置时返回 skipped。全量 Python 回归 2334 项通过、5 项按条件跳过；联合重点回归 172 项通过、4 项按条件跳过。单独启用真实 Chromium 后，私有任务历史的 14 项全部通过；浏览器断言覆盖聊天正文、打开原稿和刷新后重开。
