# 私聊回查长期目标与历史成果

在临时 Studio 业务库中建立长期目标、子任务和带出处的选材原稿，保存号主改稿后再创建 54 项任务，使原任务退出活动列表。测试通过认证私聊入口按任务 ID、BV、完整来源、理由原文和目标查回成果。路由由脚本化模型驱动；查询、版本读取、权限校验和浏览器均使用实际实现。

- 编辑角色卡或更换运营账号后，号主能回读同角色的原稿。改口仍受原执行授权约束。跨角色、未映射作用域及已撤销记忆的版本不可召回。
- “我上次为什么选那段？”可以回到上次讨论的版本；如果号主编辑后的稿件另有原稿，语义路由可选择原版核对理由。原稿与号主改稿使用各自的版本坐标。
- 真实 Chromium 从对话输入问题、展开回答下的原稿并核对来源链接，刷新后再次打开同一版本。公开动态、直播交接和临时聊天未获得回查正文。关闭历史引用后再次打开来源被拒，生成中关闭时没有输出正文片段。
- 本轮未调用工作站推理，平台写入为零。联合运行私有任务回查、记忆、私聊、任务身份、创作工作区和 Omni 隔离回放，共 76 项通过。

复现专项目录中的测试可运行 `uv run --locked pytest tests/test_private_task_history.py -q`。设置环境变量 `TUBER_TEST_CHROMIUM=1` 运行其中的真实浏览器用例。Windows 使用新启动的 Edge Chromium 实例，其它系统使用 Playwright Chromium。
