# 私有视频选材的逐项回执与前台校验

2026-11-19 核对。账号、作品链接、帧、正文和工作站连接资料保存在本机私有运行目录。

| 检查 | 观察 |
| --- | --- |
| 真实应用的网页读取 | 投稿页返回所选分 P 和 CID；节目页正文可查剧名和导演。核对使用公开只读适配器。 |
| 已观测的交付失败 | 工作站读取四个时段共十二个画面。运行中曾发生网页调用遗漏分 P 参数、前台预留输出过多、审查将未展示的旁证误作拒绝对象。取材成功与首版、改口版交付分别验收。 |
| 输入和输出预算 | HTTP 隔离测试中模型卡窗口为 8192，结构化输入计量为 4678，实际 Chat 请求分配 3514 个输出 token。输入占满窗口时返回预算诊断，完成接口调用数为零。 |
| 来源与范围 | 混合读取批次中，错误时段只产生自己的参数回执，同批合法网页仍取回正文。无正文的给定链接进入程序生成的覆盖说明。前台编辑与审查读取相同的时段、实际采样点和领域缺口。 |
| 字段修正 | 拒绝意见绑定本次交付的字段、其原文和受限的理由类型。修正仅覆盖被点名的文字；任务重启能取回原稿及意见，修正后再次审查。二次拒绝时成果库无新版。 |
| 原项复用 | 隔离编辑测试按上一版实际主帧 ID 复用完整原项，第二项引用另一主帧。测试同时验证未展示的旁证不能成为合法的拒绝路径。 |
