# 私聊、指定视频与直播交接

- 受控回归通过号主聊天提交带姓名和内部链接的背景，再从指定视频队列取 P1 的 0–5 秒。平台读取使用 BV 和 CID，卡片返回 P1 时码。断言私聊姓名和内部链接未进入取材任务。直播模型仅收到净化文字、公开角色表达和本场适用的表达规则，Provider 自动身份注入也不带账号资料。
- 在首次合成完成后、播放器连接前删除直播偏好。播放边界拒绝第一次生成的台词，任务从当前材料重建。播放器确认播完后，号主聊天卡和历史查询返回实际台词，新场次未继承待播任务。
- 隔离 Chromium 从聊天发起取材与直播交接，使用正常 overlay 播放测试 WAV 并收到结束事件。浏览器为测试配置允许自动播放。随后从聊天将浇水动作交给模拟游戏，工作台完成接管和交回。API 回归验证接管期间只允许手动操作，重建模拟服务后恢复实际游戏日和控制权。
- 部署后用实际工作台读取公开视频的 P2 02:10–02:24。字幕及画面发现包含 132.400、135.000、135.260、138.840 和 143.200 秒的时码，任务完成。直连模型接口报出微调 9B。实际交接生成了纯文字和 4 个时码引用，测试姓名和内部链接未出现在交接文字。直播模式资源节点报告 MiniCPM5-2B，首次尝试未取得播完回执，复试的结构化调用失败。真实 9B、语音和播放的连续验收仍未完成。平台零写入。
- 收紧 Provider 身份注入后重载，受影响的 33 项测试通过。再次从实际工作台进入本地直播会话时，推理节点切档超时。工作台恢复到运营模式，直播处于停止状态。
