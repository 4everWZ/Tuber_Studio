# 私聊、指定视频与直播交接

- 受控回归通过号主聊天提交带姓名和内部链接的背景，再从指定视频队列取 P1 的 0–5 秒。平台读取使用 BV 和 CID，卡片返回 P1 时码。断言私聊姓名和内部链接未进入取材任务，直播模型仅收到净化的文字和本场适用的表达规则。
- 在首次合成完成后、播放器连接前删除直播偏好。播放边界拒绝第一次生成的台词，任务从当前材料重建。播放器确认播完后，号主聊天卡和历史查询返回实际台词，新场次未继承待播任务。
- 隔离 Chromium 从聊天发起取材与直播交接，使用正常 overlay 播放测试 WAV 并收到结束事件。浏览器为测试配置允许自动播放。随后从聊天将浇水动作交给模拟游戏，工作台完成接管和交回。API 回归验证接管期间只允许手动操作，重建模拟服务后恢复实际游戏日和控制权。
- 取材与模型使用受控输入，平台零写入。目标 9B 推理节点探测超时，真实 9B 的脱敏质量、现场语音和真实视频连续链路仍需联合验收。
