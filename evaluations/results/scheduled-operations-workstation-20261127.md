# 定时运营与制片 · 工作站实测 · 2026-11-27

工作站以正式业务库的私有副本、当前 Aqua v3 角色卡和同一 Omni 网关回放。所有时间按台北时区。样本覆盖定时结束、收尾动态、单独的视频制作时段、真实配音、Remotion 出片和投稿审核。

## 运营结束与制片

- 回放 11 月 20 日的实际运营窗口。快照按投稿去重记录 143 次观看，保存 219 条评论提交回执、0 条当时库中标记为公开读回的评论和 1 条动态发布回执。历史审查另有逐条 B 站页面证据。收尾正文和视频引用同一个快照，数据图分别显示回执数和公开读回数。
- 运营结束时得到一条原账户的待审核收尾动态。制片窗口打开前未建视频任务。到达窗口后建立并渲染唯一视频，随后再次执行定时器仍沿用原任务。
- 最终样片 19.371 秒、3 镜、1280×720。FFprobe 读回 581 帧 H.264 和 AAC 音轨，生成了封面、字幕和逐镜预览。投稿目录在画面上保留准确标题、作者和简介中的原片链接，Aqua 的旁白按实际配音时间生成字幕。样片在工作站审核状态，账本发布增量为 0。
- 原测试曾把书名号尾部拆成仅有标点的请求，网关明确返回 HTTP 400。分句保留原标点并归回相邻正文后，同一条台词取得转写校验通过的 5.28 秒音频。完整样片随后复验通过。

## 投稿和界面

B 站创作中心用当前登录完成只读能力探测。匿名页面从一份已有视频回执核对到稿件及原作者归属。自动时段投稿用统一写入账本验证，覆盖运营关闭后仍可按单独授权提交、临提交撤销窗口、重复请求防重和未知结果读回。工作站样片没有新建 B 站稿件。

Edge 通过真实本地 API 验证了两个定时配置入口、跨日时段、设置修改、手动制片、页面刷新和精确定位视频。视频工作台只读核对旧回执，顺序显示平台收稿、公开状态未知与已核实公开，并使用真实返回字段打开公开地址。浏览器测试的提交回执使用本地夹具。

## Aqua 与直播

真实网关曾返回结束状态且可见正文为空。保留原思考配置和事件结构后，前台能收到可见台词和分开的推理字段，台词按原事件校验。工作站回放中，Aqua 把换头像归给视频作者，再表达自己想调整呆毛的联想。余额和停机传闻被她明确标为无实据，停机留作假设。直播冷场轮换在隔离播放器测试中通过了排队、弹幕优先和播完回执，没有开启 B 站直播。

工作站部署 `086b03c` 后通过容器健康、已认证的角色与定时计划查询、数据库迁移及运营待命核验。切换前完成业务库快照并保留原镜像。已有定时计划保持原运行设置，新收尾选项分别由操作者配置。

## 正式平台短轮

在原有运营计划仍按既定时间运行时，额外排定 18:13–18:18 的短轮。同一时期正式库记录 7 条待审核的公开评论草稿和 3 条点赞成功回执。首次上线的复盘口径只统计新增观看、评论提交与公开读回、动态发布，因此本轮对这些项报告为零。后续版本将待审评论和点赞回执纳入同一个快照。

18:18:03 发布收尾动态，18:20 开始独立的制片窗口。工作站使用 Aqua v3 与真实 Omni 配音渲染 1080p MP4，FFprobe 确认 13.206 秒。18:21:51 自动投稿并取得 B 站稿件回执。两条内容均从实际匿名页面核对到；视频公开校验同时匹配原稿件和账号。只提交了本次授权的动态和视频各一条。投稿结算后，视频工作台的常设策略恢复人工预览。

## 评论公开可见性复核

四条触发告警的评论都能以发送账号在原楼查到，作者、正文与楼根和父评一致。匿名直达和楼内分页都未读到这四条，匿名页仍能找到对应父评。另取同一写入链路的三条旧回复，全部仍可匿名读回。七条的初始回执均未标记回复隐藏，提交时的提示无法代替公开读回。平台未返回这四条的公开分发原因。

旧保护状态把 02:51–03:22 的三条与 18:00 的一条合并计算，复查同一个回执也可能把截止时间后移。修复后按原发布时间分段计数，旧的读回只改变对应评论；冷却到期后保留历史记录并停止显示暂停。评论列表漏项增加了页面的评论 ID 定位，两侧全部找不到时保留未确认。修复过程没有重发评论或更改当前草稿审核权限。

工作站部署 `b423a77` 后，重新读取最新仅自己可见的评论和较早的公开对照评论，两条的可见性保持各自结论，原冷却截止时间仍为 18:30:32。正在运行的原日常排程已恢复，HTTPS 工作台可访问。用更新后的统计重算短轮得到 7 条待审稿和 3 条点赞回执，两条正式稿件继续沿用原回执。

18:30:32 后原暂停状态解除。既有人工批准队列随后提交的三条回复先后读回为仅自己可见、公开可见和仅自己可见。部署 `5792f03` 后复查仍一致。新一轮只计一条，旧截止时间没有继承给它，运行状态仍为正常运营。相同写入渠道在同一轮同时出现公开和仅自己可见的结果，平台仍未返回限制原因。
