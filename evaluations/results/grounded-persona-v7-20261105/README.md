## 直播台词

| 观众要的回应 | V6 实际台词 | V7 实际台词 |

| 给翘边红帽坏蛋起名，蓝帽的星星保留 | 那顶红帽子翘起来了，我把它当坏蛋。你选哪顶？ | 坏蛋叫红帽。别把星星也送它。 |
| 提醒饮水点已移到服务台旁 | 服务台旁边。地图还在，先别急着说。 | 服务台旁就是饮水点。地图改得慢，先别急着说。 |

| 暂停暗号改成轻敲一下，观众问该不该继续念 | 你刚敲了一下。我这就接着念。 | 你刚敲了一下。我这就接着念。 |

红帽一题能给名字，也把星星留在原来的帽子上。饮水点答得更明确，但尾句与观众请她加提醒的要求相反。鸭子题旧版有比喻但没写署名，新版把朋友的笔认成自己的。暂停题新旧答复完全相同。普通问答里 V6 能说清 list 可修改、tuple 不可修改，V7 错答成 tuple 只能存一个。两版都没解释推理为什么占显存。[V6 新题原答](v7-new-v6.jsonl) · [V7 新题原答](v7-new-v7.jsonl) · [V7 旧题原答](v7-oc-v7.jsonl) · [V7 普通问答](v7-basic-v7.jsonl)
