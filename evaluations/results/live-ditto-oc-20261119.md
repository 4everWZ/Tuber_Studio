# 工作站直播 Ditto 角色锚定

在役 Ditto 未能为指定形象建立渲染参考。工坊将直播神经口型标记为 TBD；Pets 开启时沿用当前角色的一只 pet 和实际播放音频，Pets 关闭时保留语音与字幕。私有电话始终使用原生双工语音。

正式准入须用实际收端录像逐一验证 Q 与 mature 的完整半身、原画身份，以及说话和停顿时可信的头肩、躯干与脸部动作。只动嘴不合格。本次失败发生在渲染前，没有可供该项验收的新录像。[产品准入条件](../../docs/specs/tuber-studio.md)

| 输入 | Q | mature |
|---|---|---|
| 号主批准的两张 1182×1330 成图 | 参考准备失败 | 参考准备失败 |
| 两张 1448×1086 设计母稿此前用于 Ditto 的头部裁图 | 参考准备失败 | 参考准备失败 |

两张成图按完整源文件 SHA-256 与批准清单核对，再按 Portrait 的上传规则归一到 640×720。两张母稿按原件 SHA-256 核对，使用旧实测交接保存的 640×720 裁图。四次请求均由工作站 Studio Core 通过普通应用凭据发给同机在役网关，串行提交。返回均为 `failed / reference_preparation_failed`。服务端四份栈均停在 `source2info.__call__`，人脸裁切函数返回空，无法解出裁图、变换矩阵和地标。失败发生在创建媒体会话之前。[获准成图](approved-oc-rigs-20261119.md)

在役 Portrait 容器健康，Avatar 挂载了它的控制 socket。原有七项生成记录均有准备结果与预览；其中零项预览的 RGB 与获准 Q、mature 成图的规范化像素匹配。早先的隔离版本曾用人工眼部校准让母稿进入 ready 并实播，当时两份录像均未观察到闭唇。在役版本的注册入口缺少该校准参数。这两类结果都不足以将现有形象验收为大肥鱼直播口型。[旧校准与口型录像分析](ditto-master-mouth-20261118.md)

本次四个临时 generation 和各自的上传 asset 均通过应用 API 删除。结束时仍有原来的七项 ready 记录；Core、网关、Avatar、Portrait 均健康。未改正式工坊库、活动登记和模型状态。各输入的应用回包摘要留在本机 `runtime/private-artifacts/live-ditto-oc-check-01/`、`live-ditto-masters-check-01/`。原有 OC、Inochi 绑定、通话录像和 90 秒成绩继续留存。
