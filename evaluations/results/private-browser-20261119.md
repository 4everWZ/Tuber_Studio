# 私有任务浏览器隔离验收

11 月 19 日在临时 Studio 数据库和新建的 Chromium 配置中运行。活动页使用实际 UI 模块和管理 API，后台使用脚本化 Responses 调用，公开文档由隔离传输提供。阅读工作进程运行真实 Chromium。验收期间工作站推理调用和真实平台写入均为零。

- 从活动页交办两份公开来源，后台工具打开第一份。号主看到 960 像素宽的实际视口并接管，展开前后的文字回执有可核对的区别。
- 接管前后核对 Chromium 页面标识；释放工作进程后重新操作，页面标识变化，已展开的正文仍在原视口。打开第二个授权来源并交回后，角色读到附录正文。未授权链接未成为可执行控件。
- 核验公开 HTTPS 来源、DNS 固定、无 Cookie 与认证头、重定向、非公网解析和超限文档；跨任务步骤、旧控制版本、撤权后的在途读取、改口及停止均不能存入新回执。重新打开数据库后保留原控制方与位置。

运行 `uv run --locked pytest tests/test_private_browser.py tests/browser/private_browser_acceptance.py -q`。浏览器验收需要安装所选 Chromium 渠道。它验证真实浏览器交互与任务授权；模型自然表达及公网特定站点的可用性另行验收。
