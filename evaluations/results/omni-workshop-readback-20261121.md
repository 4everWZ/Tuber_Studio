# Omni 工坊检索与任务回流 · 2026-11-21

对照使用工作站当前 Omni 网关、相同角色预设及两份独立的隔离数据库。浏览器走工作台消息框和 SSE 接口。视频、网页和帖子使用隔离数据及受控传输。正式库和真实平台写入均为零。

| 路径 | 观察结果 |
| --- | --- |
| 原版观看对话 | 询问数量、分享内容及索取链接三轮均返回直接聊天。工具读取为零。 |
| 新版观看对话 | 账本有四次开始、三个 BV，其中一个有两次记录。正文读回两条已取得内容、一条在读。分享取到已保存的画面观察，追问打开先前提到的视频 P2 第 19 秒。浏览器打开的链接和来源回执一致。 |
| 保留问法 | 换成「这天实际读到了几部」「讲讲你刚读到蓝色灯塔的那部」「把那一段的地址给我」，核对同一 BV、分 P、时码及零后台任务。相同标题的另一部视频提供不同的画面观察。 |
| 动态交办 | 接单后先显示三条具体待发稿。插入闲聊，任务总数仍为一，确认前提交为零。测试端记录三次逐条提交，其中两次成功并返回编号，另一次被拒。原对话主动收到分项结果。浏览器点开对应的测试帖子，刷新后链接仍在。 |
| 独立研究 | 读取两份受控网页。在同一任务上把便笺改成两栏对照。关闭页面再打开，原对话交付新修订，下载的 Markdown 带两边出处。 |

回归测试另外覆盖账号隔离、同名来源选择、清空后失去旧引用、单轮连续读取、提交后超时和后台恢复。来源问答的自然语言仍由 Omni 生成，验收以实际来源 ID、程序统计、任务状态和平台回执为准。
