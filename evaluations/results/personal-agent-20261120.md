# Personal Agent 验收 · 2026-11-20

使用工作站当前 Omni、隔离 Core 和 Edge。角色绑定使用隔离账号。外部请求仅包含网关推理、公开检索和开页，公开发布、私信提交、自动发送和越界请求均为零。

| 场景 | 核对结果 |
| --- | --- |
| 身份与设置追问 | 当前绑定昵称、UID 和主页来自已核验的同一对象。查画布后只追问高度得到单字段读回，转题后直接接话。 |
| 当日新闻 | 普通 Chats 触发公开检索并打开报道，成功回放分别核验到 4 篇和 1 篇 11 月 20 日发布的报道。网页中的日期和链接出现在 SSE 的最终事件及页面来源卡。旧网页的搜索摘要日期未用作发表日期。 |
| 后台续办 | 原任务由第一版进入第二版，任务编号一致。第二版读到自主运营待命，保存的第二版便笺与回执一致。 |
| 通话文字 | 用隔离语音传输夹具打开通话，从通话内发文字到真实 Core。只建立一项任务，挂断后在窄屏 Chats 找到同一份回执。 |
| 重启接续 | 预约并暂停一项游戏状态任务，重启隔离 Core，再从新会话的窄屏页面回查。恢复后任务编号、修订和预约时间一致。 |

Python 测试 185 项通过、1 项跳过，前端测试 22 项通过。覆盖新旧绑定、撤权、时间跨日、任务步骤完成后暂停、定时和事件跟进、私有通话及前台回归。留出场景和观察条件见 [留出验收](../personal_agent_holdout.md)。

## Chats 入口重放

正式库的只读检查确认，原新闻、待发动态和近况三轮都被保存为闲聊，且回复正文相同。隔离库设置了相同的旧重复回复、当前角色的两条稿件及另一个账号的一条稿件。使用真实 Edge 浏览器和工作站现用 Omni 通过 Chats 的 SSE 入口重放。

| 场景 | 核对结果 |
| --- | --- |
| 当日新闻 | 搜索并打开来源，四篇可读报道的日期均为工坊时区的 11 月 20 日。页面显示真实链接。 |
| 处理旧动态 | 读取当前账号一条已审核、一条待审核稿件。展开草稿显示现有发布入口。 |
| 转回闲聊 | 返回新对白，工具调用为零。 |
| 直播和身份 | 直播卡读回会话已停止且静音关闭。号主确认后省略对象追问地址和编号，读取同一绑定的主页和 UID。 |
| 持续任务 | 自然交办以同一任务编号持久化，刷新后对话仍显示任务卡。任务读取了一次直播状态并完成。 |

网关用文本 Responses 选择工作方式。前台模型在普通对话分支生成对白，业务查询交付领域的实际读回。发布前的账号写入、公开发布尝试、私信尝试和任务代回尝试均为零。相关 pytest 检查 115 项通过，另复验计划和来源边界 17 项通过。
