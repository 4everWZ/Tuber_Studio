# 常驻 Agent、Chats 与领域接入 · 2026-11-16

在隔离业务目录中接入现行配置的 9B 推理端点，仅提交合成对话与读取任务。Agent 按要求先执行 `live_status`，再执行 `game_status`，并以两个实际工具结果汇报直播停止和《星露谷物语》当前模拟时间。该回放覆盖真实模型的多步选择、结果消费与交付。

隔离 Chromium 使用受控决策，走真实工作台提交后台任务。一个标签页打开任务后，第二个标签页从 Activity 查到同一任务、补充要求并取得结果，第一标签页同步显示。另验会话卡显示已交办任务的最终结果、角色素材、预约、纠偏保留预约时间、停止和活动分组。在 420 px 浏览宽度下核对了活动入口和关闭返回。

Python 回归覆盖保存工具检查点后重启、取消或纠偏期间中断并复用原步骤号、预约纠偏保留原定时间、切换账号隐藏旧任务、已经提交的只读视频轮次随 Agent 停止。直播测试接真实本地播放器协议并用受控生成和合成，确认等待审批期间未提交、播完回执到达前没有完成结果。模拟游戏测试覆盖确认前无动作、接管后旧批准失效，以及后续有新动作时仍能按旧编号取回原结果。平台写入为零。

在隔离 Chromium 的 420×900 工作台验了记忆摘要页的主题、更新时间、原来源、自然语言询问、更正后的刷新与 Escape 返回焦点。Python 受控模型测试核对不接受模型自行填入的更正内容，应用提议时核对条目版本。真实 9B 的模糊更正、语义召回及跨场景的摘要归并分别待验。
