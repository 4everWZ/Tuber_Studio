# 自动回复取材回放 · 2026-11-15

从实际运营库只读加载两段原评论楼和对应的已存视频材料，使用隔离 SQLite、受控平台适配器和现用微调 9B 直连。网页搜索和来源读取走实际公网。B 站写入次数为 0。

| 样例 | 已确认的旧链路 | 新链路回放 |
| --- | --- | --- |
| 番茄书名与 token | 把视频标题和 00:18 的画面描述接进原评问句。 | 首个输入只有评论资料。9B 搜到了 token 的解释，仍缺番茄书名规则。一次回放选择暂缓，另一次给出未经核实的结论并被留审。 |
| DeepSeek Harness 与 RVC 自检 | 楼内两条回复分别编出收藏的歌曲版本，及与当前讨论无关的安卓、镜像问题。 | 搜索读取了投稿简介指向的 CixiSound README。最终回放只交付这份作者文档，9B 选略过，记录查到的插件能力及缺失的自检依据。 |
| 同楼另一个人的跟帖 | 模型曾只引用视频帧，正文带上别的讨论对象。 | 引用根评原话发起取材的请求被拒绝。另一次按跟帖的夜间训练接话，尝试打开的网页读取失败，候选留审。 |

RVC 文档把 F0 提取作为训练环节。CixiSound 作者文档列出转写、节奏和旋律等分析能力。实际读取范围未确认插件可以判断某个 RVC 模型成品是否达到预期听感。 [RVC 项目文档](https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI/blob/main/docs/en/cli.md) · [CixiSound 作者仓库](https://github.com/CixiSVesper/dsh-soundtry)
