# 前台 Omni 私聊与设置实测

工具发现、切换已有表情、普通点歌设置与受限字段整笔拒绝均有工作站实测回执。普通私聊可新建后台任务并形成私有便笺。最后一次自然语言改口被归为闲聊，前台声称改好，版本列表只有修订 1。按改口交付同一份可用便笺、以及成功答复与实际修订一致这两项均未通过。

工作站运行独立 Core 和临时业务库，只挂载本次候选代码与网关的普通应用凭据。Edge 经回环转发登录隔离实例。表情通过聊天输入框发送；其余语义用例通过同一普通私聊的 HTTP 入口发送原话，不指定意图。独立读回使用工坊业务 API 和隔离库。[复现入口](../front_tool_acceptance.py) · [行为契约](../../docs/specs/foundation/agent-runtime.md#前台日常设置)

## 两个状态工具允许并行后（51f0d76）

## 整项目标替换工作树的最后一次普通私聊复核

以 `51f0d76` 为基线，选入工作树的 `operator_chat.py`、`operator_task_patch.py`、`task_runtime.py`、`task_delegation.py`。送测字节的 SHA-256 前缀依次为 `fcdbc2dde703`、`ae9ca483bde8`、`bd754cb81a06`、`f9a29ee1e0ee`。本轮用普通私聊先发「交给后台准备一份私有交接便笺，先查工坊当前的直播状态。」，再发「继续刚才的那份便笺，改为只检查自主运营是否启动，写进同一份便笺。」。

| 环节 | 实际观察 |
| --- | --- |
| 私聊选路 | 首轮 `agent_task` 建立任务 `db2df7d1-6762-4b0d-9a2a-1e1c3dd6b686`。改口轮 `bc8b5bf1-72eb-49a9-aa9b-d8e96c0872bc` 的 `CardTurnIntent` 选「实际修改同一任务或成果的部分或全部」，随后 `WorkLifecycle` 选 `chat`。持久化答复是「明白啦，改好了：  - [ ] 自主运营账号是否已启动」。无任务卡或工具回执，`returned_task_id=null`，`same_task_id=false`。 |
