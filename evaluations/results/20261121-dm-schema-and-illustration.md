# 私信生成与运营配图验收

## 工作站读回

- 当前 B 站登录、会话列表和三个会话的消息读取返回 HTTP 200，平台代码为 0。私信草稿保存的失败位置是后台生成。相同草稿在只读快照的隔离副本中两次重现 HTTP 400，网关报告 JSON Schema 指针无法解析。
- `OperationReply` 的提及字段引用文档根的 `$defs`。工作台组合正文与网页工具时把正文放入 `oneOf`，原定义随正文进入分支。保留根定义后，同一工作站网关为这两份隔离草稿都返回了非空正文。运行期间外部访问仅限已配置的模型网关。

## 配图

- 用工作站当前 `llm-default` 发出五次真实结构化选图请求，生图关闭。动态原评论图、动态图库图、视频一级评论图库图、私信图库图、纯文字各取得对应选择。核对请求中的枚举、实际返回的选项和素材摘要绑定。
- 对工作站快照中的待审核动态 #15 重新选图。读取旧稿中保存的账号角色关系后，同一网关一次调用选中图库图，正文保持原样，草稿仍待审核。数据库副本中的已发动态 #14 的原正文、状态和回执均保持原样。
- 真实 Edge 经隔离 Core 测试动态正文省略配图字段后启动配图、带图预览和提交、旧草稿重新选图、漏选时阻止审核和发布、手动明确纯文字后提交。隔离平台收到一条图文动态和一条纯文字动态。楼内回复没有配图，私信按图片和正文分别取得两份回执。
- 自动测试覆盖候选耗尽、图库权限撤销、后台选择遗漏、任务重启和已知远端任务恢复。所有写入检验使用可控传输，真实平台写入为零。
