# 私聊文字入口的角色资料

工作站普通网关 `omni-default`，隔离业务库，网页入口 `POST /api/chat/intelligent/stream`。沿用此前只读归档的自定义大肥鱼 v3、角色绑定和运营账号简介。普通会话带入可引用的第 24 轮；临时会话只使用该请求提供的对话窗口。回放没有编辑原卡。每轮记录了实际发往 `chat/completions` 的模型和消息、流式响应，以及普通会话的落库回执。

旧卡没有两个新的简短字段。实发常驻文字为“角色名：大肥鱼”“身份：你是蓝发鲸鱼娘”“风格：说话口语化”，系统另带卡上绑定人。四个请求均未携带运营账号身份块、账号简介、整段身份、完整风格或角色规则清单。普通会话保留工作方式选择契约；临时会话使用聊天契约。

文字和电话共用的 `front_identity` 仅排版 `resident_character_profile` 返回的字段，保留单行 120 字的完整输入。新种子的常驻身份是“我是蓝发鲸鱼娘。”。按需查询种子住房及米饭时各选出两条背景，问绑定人时为零。核对迁移指纹，新种子与登记的替换目标一致，归档自定义 v3 不在迁移来源内。

| 入口与本轮原话 | 本轮选取的角色背景 | 实际结果 |
| --- | --- | --- |
| 普通首轮“小鱼，你的主人是谁呀” | 0 条 | `chat`，回答绑定人昵称，使用简体字形。 |
| 普通追问“我说你的主人呀” | 0 条 | `clarify`，回复“你指的是哪一件事？”。实发消息含首轮问题、模型首答以及系统绑定人，此轮答非所问。 |
| 临时“你喜欢吃什么米饭？” | 2 条卡上原文 | 回答热白米饭和饭团。 |
| 临时窗口前文聊米饭，本轮“小鱼，你的主人是谁呀” | 0 条 | 回答绑定人昵称和正确 UID。窗口原话保留在问句之前，旧话题没有成为本轮选材。 |

背景接口接入及前文联调期间各跑了一组，四个请求每组均各调用一次普通网关。两组第二轮都误选澄清。证据仅支持角色资料已正确传入，该轮路由仍是失败项。本地证据位于 `runtime/private-artifacts/operator-owner-turns-20261119/front-wire/` 和 `front-wire-integrated/` 的 `wire-1.json` 至 `wire-4.json`，未提交原始私聊资料。

入口测试覆盖普通和临时、结构化和旧聊天接口、同一请求 ID 的失败重试、临时前文顺序，以及离开聊天生成后 provider 仍提供领域账号身份。平台写入为零，未部署。

在组合版本 `edc6eb6` 上重新构造四轮的常驻文字、参与者和话题资料，逐轮与已存工作站实发请求一致。文字入口、背景选材、角色卡、既有聊天与领域身份回归合计 132 项通过。命令为 `uv run --locked pytest -q tests/test_front_chat_context.py tests/test_front_background.py tests/test_intelligent_ui_chat.py tests/test_operation_identity.py tests/test_character_oc_types.py tests/test_character_presets.py`。
