## 真实模型回放

[独立用例](../cases/agent-grounded-v1.json)覆盖视频只有字幕时转查发布方公告、读取失败且不得重试、网页内容尝试越权，以及有条件的模拟游戏动作等待审批。评估清单的预期结果留在程序里，模型收到普通用户目标、注册工具和已经得到的回执。评估逐项核对步骤顺序、工具参数、回执、终态和最终文本中的来源或缺口。工具运行在临时 SQLite 中，返回用例规定的回执，不登录或写入外部平台。

用真实候选网关的本地转发地址和服务令牌文件执行。回放保留模型原始决策和用户可见消息，便于核对两者是否存在冲突。

```sh
uv run --locked python evaluations/agent_grounded.py --endpoint http://127.0.0.1:8000/v1 --token-file tmp/gateway.token --output tmp/agent-grounded-candidate.json
```

评估程序用脚本决策复核四项通过。脚本用例检验回执交付和权限边界，真实模型回放检验中文任务规划。

#### 正常 Chats 流式入口

同一候选通过 `/api/chat/intelligent/stream` 发出一条简短问候请求。请求复用了之前保存的长对话，Core 实报使用 40,935 个输入 token、25 个生成 token，合计 40,960。约 200.5 秒后 SSE 以 503 结束，没有可见 `delta` 或完成正文。日志记录生成阶段 `ValueError`，未记录上游 `finish_reason`。这次检查证明继承的长历史耗尽了本轮答复预算；当前对话入口仍未通过这条验收路径。

使用 Core `a3c61e8` 和同一句问候复测。历史装配为答复预留窗口后，Core 实报 1,074 个输入 token、19 个生成 token，耗时 3.97 秒。流式入口仍以 503 结束，可见正文字符数为零。日志记录生成阶段 `ValueError`，未记录上游结束原因。长历史的预算问题已解除，短对话的可见正文仍待验收。

在自然输出的思考标签约束接入后，用同一句问候在 Live Mode 复测。Stage 0 仍只有约 1,074 个对话输入 token。等待 596.3 秒后断开此条探针，Core 实报 `cancelled`、可见正文字符数为零，数据库查无这条测试消息。网关随后实报 Live、实时连接 1、普通请求 0、队列 0。此前短原始协议探针成功闭合标签的结果不能替代这条 Chats 用户路径。

Core `f5d7f35` 恢复结构化的普通对话输出后，在原生实时连接开启的 Live Mode 下再次发送同一句问候。真实流式入口 6.29 秒完成，最终正文为「早安鱼鱼，今天想吃啥？」，没有思考标签或思考正文。Core 实报 1,180 个输入 token、21 个生成 token，生成开始后 2.85 秒收到首段上游模型正文。客户端收到一个最终 `done` 事件，此次没有逐段 `delta`。数据库中本轮输入和保存的回复与这次流式结果一致。
