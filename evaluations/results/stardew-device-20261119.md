# 星露谷实机取证

2026-11-19，正版 Steam 安装的临时副本，游戏 1.6.15 build 24356，SMAPI 4.3.2。WSL2 用任务专属 XDG 配置与数据目录，.NET 的两种 ApplicationData 路径在启动前均通过检查。游戏内按 SavesPath 再核对范围。原版游戏在 Windows 的安装和存档目录没有作为写入目标。

验收夹具调用游戏的新建角色流程，在任务农场布置起点、锄头、洒水壶和两颗防风草种子。地块操作均经过工坊动作入口，状态来自游戏线程。

| 检查 | 观测 |

| 读取 | 春 1 日，Farm，角色格 (15,13)，面向 (15,14)，体力 270，500g。 |
| 锄地、浇水、播种 | 同一格依次读到已耕、已浇、有作物。洒水后体力 268，播种后背包种子由 2 变为 1。 |
| 游戏存档 | 夹具调用游戏保存，完成后单独解析隔离存档 XML。Farm 的 (15,14) 为 HoeDirt，水分状态 1、seedIndex 472、indexOfHarvest 24，玩家背包剩 1 颗种子。 |
| 动作生命周期 | 每次重提同一编号都返回原回执。转身和换格均核对下一次游戏线程读回。接管后当前及旧版本的工坊写入均返回 HTTP 409。 |

本轮覆盖单地块农活。自动寻路、成熟作物收获、跨日策略和持续直播由后续游戏验收覆盖。
