# 大肥鱼 OC 第五轮

原角色卡参考的四份文件里没有「鱼鱼」。公开同人角色卡的「可爱的妹妹」版把它用作昵称和自称，「大肥鱼·迟迟」版也把它当熟人昵称。我们沿用现有项目里的大肥鱼设定。新增对白里只有一次「鱼鱼」，由观众开口，角色可以自然回应。[社区角色卡](https://aigengtu.com/persona#:~:text=哥哥可以叫你) · [项目角色卡](../../../config/characters.json)

社区讨论用「鱼八股」指反复出现的人格话术。评论区的例子包括复述视频之后再加鲸鱼自称、白饭或 Token。审稿也检查句式，比如每轮复述观众原话、每轮都转向提建议、把具体事硬写成海洋比喻。保留顺势调侃、临场改口、有来有回的分工，以及只说一句也够的场景。[社区讨论](https://www.bilibili.com/video/BV1W6nq6AEm5/) · [评论区现象记录](https://news.mydrivers.com/1/1160/1160166.htm)

## 数据

从已登录的 DeepSeek 网页发出虚构场景，提交前确认 DeepThink 控件开启。六批返回了完整 JSON，共 36 条原稿。对白经逐轮挑选和改写，缺少合适原稿的场景由项目补写。最终保留 30 组，19 组从 ChatAnime 原始处境改编，11 组为项目原创新情境。数值 ID 对应原场景，24 组用于训练，6 组整组留出。[网页原稿](deepseek-web-drafts.json) · [入库对白](../../../tools/training/grounded_deepthink_dialogues.txt) · [ChatAnime 原始数据](https://github.com/LanlanQiu/ChatAnime/blob/2169710041b1130b79530be610c0adef886f96fb/data/human.json)

- 纸月亮逐字保留上次两轮对白。观众说纸角压皱后，鱼说「皱角正好当云边」，再提议分工试三秒。
- 展台灯在第一轮问「你帮我看看背后有没有拨轮？」观众确认有并说灯开始闪之后，鱼把摊主的满电估计与眼前这盏的状态分开。
- 游戏小屋那段先拿反装的门开玩笑，后来听到朋友天天浇花，回应「他嘴上嫌门，脚倒是天天往那儿去。下次给他留个小水壶。」

原 V4 训练和验证记录逐条保留。每组新增一条纯文本两轮样本和两条实际直播协议样本，共 1008 条训练记录、138 条验证记录。MiniCPM‑V 4.7 以 V2 适配器作起点，单卡 RTX 3090、学习率 `1.8e-5` 续训一轮。通用问答沿用旧数据。[复现命令](../../../tools/training/README.md)

## 对照方法

另写 8 个不入库的直播场景，围绕道具归属、观众指定的语气或分工、约定和台词。工作站用 V2、V4、V5 三版 Q4_K_M、相同的原生 llama.cpp 构建及实际直播 Provider，贪心解码，每轮回填模型自己的上轮台词。逐例区分是否理解场景和说起来是否自然。另复跑旧直播题、普通问答、8 个视频接梗题及 40 个原视频事实题。[新场景](../../cases/grounded-persona-v5-oc.jsonl) · [旧场景](../../cases/grounded-persona-v3-oc.jsonl) · [普通问答](../../cases/grounded-oc.jsonl) · [视频事实题](../../cases/grounded-real-video-v2.jsonl)

## 工作站结果

直播台词的总体改善有限。新题里，V2 在呼吸声题套了海浪和船的比喻，V5 提到了应该剪的后半句，但从观众视角重复原话。V5 也知道蓝盖罐装票，却没把通行证放进去或给罐子起名。报幕题回答「倒计时，我这就给你骂一句」，台词本身没有开出玩笑。旧题的破音、木勺、副驾三例里，V5 两轮台词逐字重复。阿穗欢迎题也复述了观众的两轮输入。[V2 新题](v5-heldout-v2.jsonl) · [V4 新题](v5-heldout-v4.jsonl) · [V5 新题](v5-heldout-v5.jsonl) · [V5 旧题](v5-familiar-v5.jsonl)

用 BF16 短身份提示直接复跑，V5 在呼吸声题能明确留开头、剪后半句，收纳罐也选了蓝盖。其它题依旧会串分工或说出无关比喻。这个对照同时改变了精度、推理引擎和对话格式。它表明未量化权重也会出现类似问题。基础问答中，两版 BF16 都答对 list／tuple，V5 在电梯限载与三人点餐两题退步。Q4 实际直播里两版基础问答都不稳定，V5 说 tuple「只能存一对」。本轮只查普通问答。[V2 BF16](v5-bf16-v2-continue.json) · [V5 BF16](v5-bf16-v5-deepthink.json) · [V2 Q4](v5-basic-v2.jsonl) · [V5 Q4](v5-basic-v5.jsonl)
