# P2 连续区间取材

公开视频 `BV1Hy4y1J7xH` 的投稿页与播放信息均将 P2 绑定到 CID `301983263`。在未登录 B 站的隔离运行目录中读取该分 P，逐段解析原视频 DASH 索引，在授权时窗内核对解码帧的呈现时标及持续时间。每段再次用 FFprobe 从保存的短片完整解码计数。[原投稿 P2](https://www.bilibili.com/video/BV1Hy4y1J7xH/?p=2)

| P2 窗口 | 保存并读回 | 原片人工核对 |
|---|---|---|
| 11–14 秒 | 75 帧 | 宫廷远景，画面下方出现收视率文字。 |
| 35–38 秒 | 75 帧 | 从一位戴红帽的人切到另一位，字幕在谈演员。 |
| 210–213 秒 | 75 帧 | 镜头从着黄衣的人切到穿蓝衣的人群。 |
| 230–233 秒 | 75 帧 | 前半是坐在龙纹背景前的人，后半切到另一个人，下方有涉及剧情的字幕。 |

工坊的短片文件保存在私有运行目录。明确指定至多十秒的窗口时，活动页可以直接播放取回的连续画面，端点同时验证任务可见性及取材步骤归属。前台的画面描述仍以当次视觉服务实际阅读的采样帧为限。短片编码只保留视频轨，原声可从投稿链接核对。这四段的独立对照文件另外保留了原始音轨。

230.44 秒的画面无法支持早先修订稿的「群臣跪奏」。采样帧与独立节目页也不足以认定单个镜头的角色、演员或剧情。央视节目页可核对剧名与导演，无法证明该合集每一镜的正片集号。[央视节目页](https://tv.cctv.com/v/vs4/VIDA1354525702789788.html)

## 从聊天卡观看短片

Chromium 156.0.8078.4 从号主聊天记录的「查看任务」打开原任务的两条工作站视觉回执。隔离工坊复用已保存的回执与私有短片。两条播放请求返回的完整文件分别与独立留存的 `decoded-11.mp4`、`decoded-35.mp4` 逐字节一致。两段的可见卡片均显示上述 BV、P2、CID、各自起止秒和 75 帧。原任务整体状态仍为未完成。

- 两段均观察到浏览器呈现多个视频帧。折叠时暂停，重新展开保留播放点。从卡片跳转分别打开 `?p=2&t=11` 和 `?p=2&t=35`，关闭原片标签后短片仍停在原位。原片外站请求在本地截获，本次验收覆盖跳转地址。两段均从短片内 1.6 秒继续播放至浏览器发出 `ended`。
- 活动轮询更新后保留播放器。关闭活动后焦点回到原任务卡，首个可见聊天回合与顶部偏移保持一致。
- 已登录号主的分段读取返回 206。未登录读取返回 401，另一存在的任务读取同一步骤返回 404。切换角色后原任务详情和两个短片均返回 404，已打开的活动页移除播放器。

复跑时传入保存上述两条回执及媒体的隔离运行目录，然后传入原片核对目录。测试使用临时工坊和独立浏览器会话。
