# 私聊 Avatar 隔离传输验收

2026-11-19 使用 Chromium 从 Studio 私聊页分别选择常规版和 Q 版。独立服务的 Gateway、实时源绑定、Avatar 会话、事件 WebSocket、WHEP 与 aiortc 音视频轨道均使用服务原实现。模拟语音引擎提供同一句 PCM，替身渲染器提供视频帧。测试进程使用临时业务目录与回环端口。

| 检查 | Chromium 与服务端观测 |
|---|---|
| 两套形象 | 每次会话绑定选中的独立形象 ID 和网关创建的实时源。两路通话均收到 640×720 解码画面和一条音轨。 |
| 播放回执 | 常规版采样时，回复已播 339 ms、Avatar 时间线 2517 ms；Q 版分别为 253 ms、2165 ms。静音期间新回复的已播回执为零。 |
| 打断与挂断 | 两次打断均产生新代次、替换接收器并恢复新回复回执。两次通话合计 4 次成功 WHEP 订阅，挂断后 peer 数为零。 |
| 回退 | 单独注入 WHEP 503，形象会话关闭，下一条回复以原生语音播放并收到回执。模拟可撤回记忆票据时使用原生播放，未创建新的 Avatar 会话。 |

复跑命令为 `python tests/browser/run_private_call.py --whep`。本记录验证 Studio 的传输与播放；实际两张原稿的质量判定另见[原稿实测](ditto-master-mouth-20261118.md)。

记忆票据测试记录的是首版行为。加入记忆变更订阅后的实测见[原画通话与跨端记忆撤回](private-rig-memory-20261119.md)。
