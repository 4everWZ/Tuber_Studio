# 后台读帧、记忆和前台并行验收

在工作站用隔离工坊和临时业务库运行。同一应用网关提供前台 Omni 和后台 Qwen，测试适配器没有平台写入能力。使用既有 P2 归档的 1.48 和 10.44 秒两张真实主帧，保留分 P、时码和原视频资料。

- 工坊以后台 Responses 读取两张原帧，再由同一后台模型整理观察。父任务记录三次生成、1548 输入 tokens、226 输出 tokens。前台同时发起并完成一条普通问候。独立测量中，前台与两张后台读帧的请求时段重叠 0.82 秒。
- 逐帧能概括对应的人物服饰和场景。模型仍把画面上的节目文字称为字幕，并出现未经核实的具体身份、时间推测。这是抽帧观察，不作为完整视频选段成果。
- 后台整理两个测试号主原话，一条运营汇报偏好和一条对稿约定。两条处理完成，从同一份私有记忆召回原话。原审核、修订和撤回规则依现有回归核对。
- 正式工坊业务进程未参与测试。未生成 P2 的新修订，平台写入为零。
