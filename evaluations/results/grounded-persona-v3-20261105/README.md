# 大肥鱼 OC 表现与二次元场景扩写

## DeepSeek 网页对照

用仓库原角色卡，分别在实际 DeepSeek 网页聊天中发出两轮观众台词。测试输入是项目编写的虚构情境，保留网页默认设置。原角色卡跑了四个场景，改卡草案复跑两个。网页结果用于观察台词和上下文，也用于调整角色卡。训练数据另行改写。[逐轮原答](deepseek-web-oc-reference.json)

浏览器恢复后，核对原聊天的前两轮原答并确认 DeepThink 已开启，再发第三轮。模型接住「多撑一秒」，按新要求写出车贴奖状。同一模式另外写了两条 ChatAnime 草稿，纸月亮题接住了道具变化和拍摄分工，展台灯题补出了材料里没给的拨轮，需改写后再筛选。[恢复与续聊原答](deepseek-web-deepthink-resume.json)

- **接梗和分工。** 观众说自己撑了十一秒，DeepSeek 接了「就多撑一秒也来炫耀？」并承认预言输了。副驾题的下一轮仍记得方向盘在观众手里，提议先看路牌再报路。
- **个性也会过量。** 一秒兑奖被带回白饭和软垫。禁词题在两种卡下都说出了「本鱼」。改卡草案的副驾题还补了观众没提到的花坛，素材事实与玩笑的界线仍需看实际台词。
- **角色卡。** 增加现场回嘴、承认失手、给具体小帮助的例子。规则写明保留已知分工、道具和承诺，视频玩笑从看见的细节出发。卡片继续使用现有版本机制，定制过的历史版本受保护。[角色卡](../../../config/characters.json)

## 训练数据

角色续训保留第二轮数据，加入 24 组原创两轮对话和 16 个真帧反应场景，并为直播台词、情绪和视频证据写出对应的结构化样本。验证另留 4 组原创对话和 4 个真帧场景。最终角色轮新增 104/20 条训练／验证记录。

ChatAnime 同一处境在 20 个角色下重复。按源场景 ID 合并为 60 个处境，只用第一轮观众问题的场景线索。初次本地写手批量改写后，机审保留的 56 条里仍反复插入海洋设定，整批留在工作站做反例。浏览器批量扩写在完成前断开。随后直接选 32 个源场景改写成漫展配音、番剧放映、手书、字幕组、连麦和游戏等项目台词。角色、具体道具、后续变化和回应重新写。24 组训练、8 组验证，按原场景分隔。每组有一条纯文本两轮和两条直播结构化记录，合计增加 72/24 条。[ChatAnime 原始数据](https://github.com/LanlanQiu/ChatAnime/blob/2169710041b1130b79530be610c0adef886f96fb/data/human.json) · [大肥鱼改写数据](../../../tools/training/grounded_chatanime_dialogues.txt)

## MiniCPM‑V 4.7 对照

用第二轮续训权重作共同起点。工作站 Q4 回放包括 8 个未见多轮情景和 8 个独立问法的真实视频反应题。视频反应题复用第二轮的公开视频素材，问法专门要求接梗或解说。直播使用实际角色提示组装、推理 Provider 和 JSON 校验，并回填模型上轮真实台词。视频事实仍用原来的 40 道题核对。[多轮题](../../cases/grounded-persona-v3-oc.jsonl) · [视频反应题](../../cases/grounded-persona-v3-video.jsonl)

- 角色轮普通续训有些视频回应更贴观众。例如，上一轮在技术视频题只答「她找的是新技术视频，刚翻出来个大新闻。」角色轮补到手中长方形物件并引了实帧，仍把具体物件猜成了平板。
- 加权版对 32 道可回答的旧视频题有 22 次暂缓，多轮里仍会颠倒道具归属。它留作训练策略对照。
- 单加角色说明、加三条角色示范、压缩观众输入都分别复跑。三条示范会诱发复述伞和门铃，压缩输入在小扣子题能取出「小小黄扣子」，其它场景仍常重复或串视角。
- 实际原答保留在 `v3-chat-*.jsonl`、`v3-react-*.jsonl` 与 `v3-regression-*.jsonl`。两种续训配置、权重与投影器身份见同目录的训练日志和导出清单。通用纠错数据沿用原语料。

### 加入 ChatAnime 后

从第二轮适配器以 `2.5e-5` 续训一轮，共 936 条训练、120 条验证。发布格式的 GGUF 完成 8 个多轮场景、8 个视频反应问题和 40 个旧视频问题回放。多轮仍会把观众撑了十一秒说成自己撑了十一秒，也会在明确要求保留小扣子时提议做大。看视频时有些事实和引文仍能对上，例如氢化植物油和 CANOLA 瓶，但漏了观众请它起外号的要求。缺证据题还捏造了一次体检日期。权重留在工作站 `gguf-v4-anime` 作对照。[训练日志](v4-training-anime.json) · [权重清单](v4-bundle-anime.json) · [多轮原答](v3-chat-v4.jsonl) · [视频反应](v3-react-v4.jsonl) · [旧视频回归](v3-regression-v4.jsonl)
