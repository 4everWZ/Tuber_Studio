# 工坊创作搭档：本地切换验收

改革前的工坊基线为 `ff68f29`，本地标签为 `archive/pre-creative-agent-20261118`。独立服务的协议核对基线为 `64f7ed9`。本轮全部使用隔离业务数据，真实平台写入为零。

- **数据库**：通过 SQLite 在线备份将本机业务库复制到临时目录，只对副本连续执行两次建表与旧作用域映射。副本中 8 张既有任务／草稿／尝试等相关表的行数未变，两次完整性检查通过。此项不声称已经切换正式业务库，也不证明每条记录的语义归属。
- **客户端**：隔离业务库、预置的私有材料、真实 Chromium。号主从「对话 → 活动」打开执行记录，设为长期目标、编辑私有成果；另一个标签页打开原目标读到新版并下载带任务 ID 和版号的 Markdown。未对真实视频质量或跨设备网络作出判定。
- **跨会话操作**：两个隔离 Chromium 会话分别登录同一号主。关闭第一端后，第二端改口并核对审批中的准确对象、正文和配图，假平台只收到一次指定提交。编辑成果后返回原消息，滚动偏移一致。[双会话实录](owner-activity-chromium-20261118.md)
- **工作站认证与文本工具**：健康探针返回 200，无 Bearer 的模型请求返回 401。号主授权本次回放使用普通应用凭据。真实 `/llm/v1/responses` 发起函数调用，工坊按原 call ID 回传本地查询结果，模型读回测试状态码；通过显式交办入口完成改口后的状态便笺，由 Omni 核对证据并保存 r2 私有成果。
- **实际视觉**：把自造无声 P2 动图解码为三帧送到工作站，Omni 在 0、4、9 秒分别识别出黄色三角、蓝色方块与红色圆形。出处页是受控文字样本。
- **普通对话**：重构前，Omni 把需要留存的交接便笺判为当场查询。分开生命周期和领域选择后，真实工作站从普通聊天创建任务，再从自然改口定位原任务。状态便笺回放通过，只读取了改口后指定的运营状态，最终成果为 r2。
- **公开视频 P2**：未绑定平台账号的工坊工具从号主给定分 P 的 11–14 秒区间解码视频，工作站视觉为 11.44、12.48、13.52 秒分别返回画面观察，三条回执均绑定同一个 CID。该次没有公开字幕。另对两个三秒窗口核对代表画面、解码时序及音频，制作了私有人工复核提纲。
- **视频成果验收**：真实工作站的初稿曾把相隔数分钟的采样拼成同一段，并从画面推断静音。之后提交边界核对主帧、同窗和出处关系。再次从普通对话交办时，首版未通过交付，未保存新版。此条真实视频的自动改口与第二版提纲仍待通过。

普通中文交办回放运行 `uv run --locked python -m evaluations.omni_chat_loop`。加 `--entry quick-action` 可独立验证显式交办、后台取材与 Omni 交付。双版本视频回放运行 `uv run --locked python -m evaluations.creative_video_loop`。配置使用 `OMNI_GATEWAY_URL`，应用凭据从 `OMNI_STUDIO_TOKEN` 或 `OMNI_CORE_TOKEN_FILE` 二选一。缺配置会报告 skipped。
