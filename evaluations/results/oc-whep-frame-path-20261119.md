# WHEP 稳态缺帧与打断空白的双端实测

三个 90 秒窗都指向工作站发包之后的链路迟到、重传与收端呈现。能与同一收端 Peer 对齐的 5,465 个视频帧时隙，在工作站 UDP 出口逐个找到了原视频 RTP 末包。浏览器同期解码增加 5,435 帧，实际呈现增加 4,157 帧。持续少发不能解释这批呈现缺口。

桌面从 9443 隔离 Studio 产品入口，使用普通应用授权、8ed94dd 的通话行为、正式网关与原 Inochi worker/INP。Q 单通话、Q 通话并发独立 Responses、mature 单通话串行执行。工作站先启用仅匹配本次桌面目的地址的出口探针，记录 RTP 头字段与内核发包观测时间。三次探针 socket drops 均为零。桌面保留原双轨 WebM、接收器统计、实际呈现回调，以及可呈现帧的浏览器 receiveTime。没有修改正式服务。

|---|---:|---:|---:|---:|
| Q 单 | 1,832 / 1,832 | 1,829 / 1,435 | 16.87 / 80 | 220 ms / 37 of 1,492 |
| Q 混合 | 1,793 / 1,793 | 1,783 / 1,374 | 16.20 / 82 | 220 ms / 27 of 1,428 |
| mature 单 | 1,840 / 1,840 | 1,823 / 1,348 | 15.56 / 87 | 300 ms / 27 of 1,368 |

每段用相同视频 SSRC 的首、末有效 connected 统计，按对应呈现计数找到两个视频 RTP 端点。25 FPS 在 90 kHz 时钟上每帧相隔 3,600 ticks，实发帧按不同原视频时间戳的 marker 计数。该段解码增量取两次 getStats 的差，端点可能还有正在解码或等待呈现的帧。同段统计不跨订阅；全窗 FPS 和冻结沿用原验收，不扣除换轨空白。Q 混合的普通 Responses 完成并读回 6/6。

## 缺口集中在重传附近

| 90 秒窗 | 各段原视频发包间隔最大值 | 首次重传中位耗时 / ICE RTT 中位数 | 普通帧 / 有重传帧到达额外延迟 P95 | 重传附近的呈现缺口 |
|---|---:|---:|---:|---:|
| Q 单 | 53.1 ms | 197.7 / 185 ms | 18.8 / 226.0 ms | 395 / 413 |
| Q 混合 | 52.9 ms | 194.2 / 182 ms | 18.7 / 212.0 ms | 407 / 439 |
| mature 单 | 52.8 ms | 191.9 / 186 ms | 21.2 / 229.6 ms | 477 / 506 |

各段原视频末包发出间隔的 P95 均不超过 42.4 ms。按同一原视频 SSRC 与单独的重传 SSRC 匹配 RTP 时间戳，计算原帧末包到首次重传的时间。mature 的四次 SDP 应答还确认了 VP8 PT 96、RTX PT 97、apt=96 与 FID 配对。Q 两场按同样的 PT 与唯一完全重叠的伴随时间戳集识别。额外延迟用浏览器最后收包时刻减原帧发出时刻，再减同段普通帧差值的第 10 百分位，消去两机时钟原点；这项只覆盖有呈现回调的帧。

相邻两个呈现回调之间，若视频时隙增量大于实际呈现计数增量，差值计入该段缺口。若闭区间内至少一个视频时戳有重传，则归入「重传附近」。这类区间占三场时隙的 51%、51%、59%，却包含 96%、93%、94% 的缺口。工作站稳定发帧、重传约耗一个 RTT，以及重传帧在浏览器显著晚到，共同将主要问题定位到发包后的传输恢复与播放环节。区间相关性不能为单个缺帧分摊网络、浏览器抖动缓冲和合成调度各自的责任。

## 打断与音画偏差

九次打断后 **3.605–5.077 秒**出现新轨首个真实呈现帧。按点击起算，元素挂上新轨需要 0.656–1.228 秒，ICE 报 connected 需要 2.729–3.241 秒，Peer 报 connected 需要 3.334–4.823 秒。Peer connected 到新轨首帧还需 0.254–0.417 秒。各项均取桌面同一单调时钟。这一批沿用关闭旧 Peer 的行为；数据说明了重建成本，未验收复用 Peer 时的旧音频隔离或播放回执。

沿用原验收的首发 RTP 归零口径，在每个有效呈现配对上另外找到**同媒体时刻**的原视频末包与原音频包。三个窗的出口音视频时间差绝对值最大分别为 7.01、7.49、6.40 ms。在收端超 160 ms 的 91 个配对中，两轨同媒体时刻的出口差均未超过 7.01 ms。发送时钟无需人为平移；原收端配对仍分别达到 220、220、300 ms，三窗均未准入。该指标比较视频呈现与音频同步源，不量测物理扬声器口型。
