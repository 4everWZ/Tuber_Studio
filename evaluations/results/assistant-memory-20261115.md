# 号主对话和跨端记忆复验 · 2026-11-15

## 复现与修订

运行库中的截图回合没有调用运营查询，也没有召回长期记忆。旧请求仍传入报告标题、序号和工具示例。旧版隔离热空闲中，普通闲聊重复旧报告，部分正文带有多余结构结尾。初次混合诊断还有两次短聊跑满 2048 token，分别用时约 132 秒、117 秒。

新版普通聊天按当前话题及紧邻引用决定可用工具，确定查询后再加载真实来源。仅聊天的回合使用原生正文流。浏览器回放中，截图里的「有没有什么开心的事儿」「把主人找到了嘛」和白饭闲聊均进入一轮模型生成并返回短段落。明确运营查询返回真实报告。刷新后对第二件核对作者、原话及已送达回执，三次追问定位同一个来源，由程序直接取值。跨端公开内容从原始证据提取，号主管理自己的备注及共享范围。
