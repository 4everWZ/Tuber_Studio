## 参考条件在工作站的实际路径

已安装的 vLLM-Omni 0.32.0、MiniCPM-o 4.5 AWQ、CUDA Code2Wav 路径有两处可接收参考。正式版本的纯文本 system 加顶层 `ref_audio` 已能改变最终波形。候选额外将同一 WAV 放入 system 的 `text / input_audio / text` 内容序列，采用 OpenBMB 的声音模仿上下文。台词仍由 user 单独提供。[OpenBMB 原生示例](https://github.com/OpenBMB/MiniCPM-V/blob/main/docs/minicpm_o4dot5_en.md) · [vLLM-Omni 部署配方](https://github.com/vllm-project/vllm-omni/blob/v0.32.0/recipes/OpenBMB/MiniCPM-o-4_5.md)

- Thinker 的 `minicpmo_4_5_omni_llm.py` 用 `_process_audio_input` 编码多模态音频，经 `embed_multimodal` 合入提示。固定新句、全部文字、根级参考和采样设置，只插入 system 音频，工作站实报提示由 64 增至 110 tokens，生成字数对应的输出仍为 9 tokens。此对照的输出有效时长从 3.63 秒变为 2.45 秒。
- 实际分词器模板在 `use_tts_template=true` 时追加语音起始标志。`llm2tts` 从 Thinker 的 token 和隐状态中切取该标志之后的朗读区间给 Talker。Talker 因而消费经声学上下文条件化的表示。未在生产进程中插入隐状态探针。
- Serving 层从顶层 `ref_audio` 解码波形。阶段处理器优先挑选原始多模态音频，缺省时取 serving 附带的参考，通过 `set_ref_audio` 向 Code2Wav 传递。候选两处携带同一份授权录音。CUDA 后端用按内容区分的运行时 WAV 与缓存 ID 调用 `prepare_prompt`。独立将源文件对齐至 24 kHz 和六秒窗口，与引擎已物化 WAV 的 20 ms RMS 序列比较。对应大肥鱼、瑶瑶缓存的相关分别为 0.99997、0.99999，交叉比较均约 −0.174。模型默认缓存与两者分别为 −0.045、0.191。

安装代码中，Talker 的 `_build_condition_embeddings` 把 `projector_semantic(hidden)` 与 `emb_text(token_ids)` 相加。CUDA Code2Wav 的 `_resolve_prompt` 先解析 `codes.ref`，按当前参考生成特征，`setup_batch` 初始化解码状态，`decode_batch` 或 `decode_ragged_batch` 使用这些特征和状态。在原生提示文字、Thinker 输入同为 64 tokens 的两次请求中，仅启用根级大肥鱼参考，就使输出对原参考的分数从 0.286 升至 0.705。随后保持根级参考并加入 system 音频，分数进一步升至 0.820。实机观察来自输入计量、参考缓存和输出 WAV，阶段内算子由安装代码核对。

| 原句来源 | 有效时长（秒） | F0 第 10 / 50 / 90 百分位（Hz） | 相对原声轮廓误差（半音） | 对原参考 / 留出 |
| --- | ---: | --- | ---: | --- |
| 原参考 | 4.26 | 205 / 256 / 401 | 0 | 1.000 / 0.846 |
| 旧 system 合成 | 4.56 | 194 / 242 / 334 | 2.83 | 0.853 / 0.738 |

有效时长取 10 ms RMS 高于各段峰值 −30 dB 的首尾区间，中间停顿计入。Praat 自相关法以 10 ms 步长估算 90–650 Hz 内的有声 F0。在同一句首尾区间归一为 100 个时点，以有声段之间插值的半音曲线计算平均绝对差。原句的时长和高音区均更接近参考。新句由旧播放器录音的 1.60 秒延长到 2.45 秒，语气、速度是否合适仍需听感判断。

独立的中文 SenseVoice 用最终音频识别，输入只有重采样到 16 kHz 的单声道音频。两份合成 WAV 和两份播放器录音均逐字匹配。声纹另用 3D-Speaker ERes2Net Base 200K 普通话模型。两种测量在本机 CPU 上完成。[SenseVoice](https://github.com/FunAudioLLM/SenseVoice) · [3D-Speaker](https://github.com/modelscope/3D-Speaker)

以 0.25 秒步长取合成 WAV 中有声的半秒窗，逐窗在整份原参考上搜索所有偏移，计算归一化互相关绝对值。原音自比所有窗为 1.000。原句重读的 16 个窗中位数 0.367、最高 0.836；新句的 10 个窗中位数 0.356、最高 0.549。缩短到 0.1 秒后，原句、新句最高为 0.941、0.916。结果支持两句经过重新合成，未发现直接复制参考波形。听感交付保留原始播放速度与音高。
